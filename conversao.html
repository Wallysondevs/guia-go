Conversão de tipos

Go nunca converte tipos sozinho: somar int com float64 não compila. Você pede a conversão de propósito. Entre números, com T(valor); entre texto e número, com o pacote strconv, que devolve um erro quando o texto não é um número.

Você vai aprender
  • Converter números com float64(x), int(x) e ver o que se perde.
  • Transformar número em texto com strconv.Itoa e texto em número com strconv.Atoi e ParseFloat.
  • Ler o erro de um texto que não é número.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Entre números: T(valor)

package main

import "fmt"

func main() {
	a := 10
	b := 2.5
	fmt.Println(float64(a) * b)
	fmt.Println(int(b * 3))
	negativo := -7.9
	fmt.Println(int(negativo))

	var grande int = 300
	fmt.Println(uint8(grande))
}
$ go run main.go
25
7
-7
44

Converter para int corta a parte depois da vírgula, sem arredondar: int(negativo), com negativo valendo -7.9, dá -7. E converter para um tipo menor pode perder informação: 300 não cabe em uint8 (vai até 255) e vira 44 (300 − 256).

2. Entre texto e número: strconv

Itoa é “integer to ASCII” (número para texto) e Atoi é o contrário. As funções que leem texto devolvem dois valores: o resultado e um erro, que é <nil> quando deu certo:

package main

import (
	"fmt"
	"strconv"
)

func main() {
	idade := 30
	texto := strconv.Itoa(idade)
	fmt.Println("Idade: " + texto)

	n, err := strconv.Atoi("42")
	fmt.Println(n+1, err)

	preco, err := strconv.ParseFloat("19.90", 64)
	fmt.Println(preco*2, err)

	ok, err := strconv.ParseBool("true")
	fmt.Println(ok, err)

	fmt.Println(fmt.Sprint("valor=", 3.5))
}
$ go run main.go
Idade: 30
43 <nil>
39.8 <nil>
true <nil>
valor=3.5
Cuidado com string(65)

string(65) não dá "65": dá "A", o caractere de número 65. Para número em texto, use strconv.Itoa. O go vet avisa desse engano.

3. Quando o texto não é número

package main

import (
	"fmt"
	"strconv"
)

func main() {
	n, err := strconv.Atoi("doze")
	fmt.Println(n, err)

	_, err = strconv.Atoi("99999999999999999999")
	fmt.Println(err)
}
$ go run main.go
0 strconv.Atoi: parsing "doze": invalid syntax
strconv.Atoi: parsing "99999999999999999999": value out of range

O erro diz a função, o texto e o motivo: invalid syntax (não é número) ou value out of range (número grande demais). A aula Erros mostra como reagir com if err != nil.

Quando dá errado

Atribuir sem converter

Compila, mas faz outra coisa. O go vet pega:

Referência rápida

Você escreveO que faz
float64(x), int(x)Converte entre números (int corta a fração).
strconv.Itoa(n)int → string.
n, err := strconv.Atoi("42")string → int, com erro.
strconv.ParseFloat(s, 64)string → float64.
fmt.Sprint(…)Qualquer valor → string.

Missão: o programa recebe a quantidade como texto. Converta com strconv.Atoi e escreva o total (quantidade × 3). A saída deve ser total: 15.

package main

import (
	"fmt"
	"strconv"
)

func main() {
	quantidade := "5"
	// converta e calcule aqui
	fmt.Println("total:")
}

package main

import (
	"fmt"
	"strconv"
)

func main() {
	quantidade := "5"
	n, err := strconv.Atoi(quantidade)
	if err != nil {
		fmt.Println("erro:", err)
		return
	}
	fmt.Println("total:", n*3)
}

total: 15

Missão: calcule a média de 7 e 8 como float64. Sem converter, (a + b) / 2 dá 7. Converta para que a saída seja média: 7.5.

package main

import "fmt"

func main() {
	a, b := 7, 8
	media := (a + b) / 2
	fmt.Println("média:", media)
}

package main

import "fmt"

func main() {
	a, b := 7, 8
	media := float64(a+b) / 2
	fmt.Println("média:", media)
}

média: 7.5

Resumo

  • Go não converte sozinho; use T(valor) entre números.
  • int(x) corta a fração; tipos menores podem perder informação.
  • Texto ↔ número com strconv, que devolve um erro quando o texto não serve.
