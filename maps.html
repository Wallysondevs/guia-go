Maps

Um map é um dicionário: você guarda um valor sob uma chave e depois busca pela chave. Nome → idade, produto → preço, palavra → quantas vezes apareceu. Nesta aula você cria, lê, apaga, testa se a chave existe e descobre que a ordem do map não é garantida.

Você vai aprender
  • Criar com map[string]int{…} ou make, ler e gravar com m[chave], apagar com delete.
  • Distinguir “não existe” de “vale zero” com v, ok := m[chave].
  • Percorrer com range e ordenar as chaves para ter uma ordem fixa.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. O básico

package main

import "fmt"

func main() {
	idades := map[string]int{
		"Ana": 30,
		"Rui": 25,
	}
	idades["Bia"] = 41
	idades["Rui"] = 26
	fmt.Println(idades["Ana"], idades["Rui"], len(idades))

	delete(idades, "Bia")
	fmt.Println(idades)

	fmt.Println("Zé:", idades["Zé"])
	if idade, ok := idades["Zé"]; ok {
		fmt.Println("achei:", idade)
	} else {
		fmt.Println("Zé não está no map")
	}
}
$ go run main.go
30 26 3
map[Ana:30 Rui:26]
Zé: 0
Zé não está no map

Ler uma chave que não existe não dá erro: devolve o valor zero (0 para int). Para saber se a chave existe de verdade, use a forma com dois valores: o segundo, ok, é true só se a chave estiver lá.

2. Percorrendo em ordem e contando

O range num map entrega as chaves numa ordem que muda de uma execução para outra, de propósito. Quando a ordem importa, junte as chaves num slice e ordene. E como chave nova começa em zero, contagem[p]++ conta palavras numa linha só:

package main

import (
	"fmt"
	"sort"
	"strings"
)

func main() {
	estoque := map[string]int{"café": 3, "pão": 12, "leite": 5}

	chaves := make([]string, 0, len(estoque))
	for k := range estoque {
		chaves = append(chaves, k)
	}
	sort.Strings(chaves)
	for _, k := range chaves {
		fmt.Printf("%-6s %2d\n", k, estoque[k])
	}

	contagem := map[string]int{}
	for _, p := range strings.Fields("o gato e o rato e o pato") {
		contagem[p]++
	}
	fmt.Println(contagem)
}
$ go run main.go
café    3
leite   5
pão    12
map[e:2 gato:1 o:3 pato:1 rato:1]

O fmt.Println de um map escreve as chaves em ordem alfabética, por isso a última linha sai sempre igual.

Quando dá errado

Gravar num map nil

Um map só declarado (var m map[…]…) pode ser lido, mas não recebe valores: precisa de make ou {}.

package main

import "fmt"

func main() {
	var precos map[string]float64
	fmt.Println(precos["café"])
	precos["café"] = 4.5
}
$ go run main.go
0
panic: assignment to entry in nil map

goroutine 1 [running]:
main.main()
	/home/ana/projetos/erro-map/main.go:8 +0x8f
exit status 2

Corrija com precos := map[string]float64{} ou make(map[string]float64).

Tipo que não pode ser chave

A chave precisa ser comparável com ==. Slices não são:

package main

import "fmt"

func main() {
	m := map[[]int]string{}
	fmt.Println(m)
}
$ go run main.go
# command-line-arguments
./main.go:6:11: invalid map key type []int

Referência rápida

Você escreveO que faz
m := map[string]int{}Map vazio, pronto para usar.
m[k] = v, m[k]Grava, lê (chave ausente → valor zero).
v, ok := m[k]ok diz se a chave existe.
delete(m, k)Apaga a chave.
for k, v := range mPercorre (ordem não garantida).

5. Em que ordem o range percorre um map?

Missão: crie um map capitais com "PE": "Recife" e "BA": "Salvador", acrescente "CE": "Fortaleza" e escreva capitais["CE"]. A saída deve ser Fortaleza.

package main

import "fmt"

func main() {
	capitais := map[string]string{}
	fmt.Println(capitais["CE"])
}

package main

import "fmt"

func main() {
	capitais := map[string]string{"PE": "Recife", "BA": "Salvador"}
	capitais["CE"] = "Fortaleza"
	fmt.Println(capitais["CE"])
}

Fortaleza

Missão: use v, ok := m[chave] para testar se "uva" está no estoque. Se não estiver, escreva uva: em falta.

package main

import "fmt"

func main() {
	estoque := map[string]int{"maçã": 4, "pera": 0}
	fmt.Println("uva:", estoque["uva"])
}

package main

import "fmt"

func main() {
	estoque := map[string]int{"maçã": 4, "pera": 0}
	if q, ok := estoque["uva"]; ok {
		fmt.Println("uva:", q)
	} else {
		fmt.Println("uva: em falta")
	}
}

uva: em falta

Resumo

  • map[chave]valor: grave com m[k] = v, leia com m[k], apague com delete.
  • Chave ausente devolve o valor zero; use v, ok := para saber se existe.
  • A ordem do range não é garantida: ordene as chaves quando importar.
