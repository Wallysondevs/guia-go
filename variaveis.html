Variáveis (var e :=)

Uma variável é uma caixa com nome onde o programa guarda um valor. Em Go toda caixa tem um tipo fixo: uma caixa de int só guarda números inteiros. Nesta aula você cria variáveis com var e com := e descobre o “valor zero”.

Você vai aprender
  • Declarar com var nome tipo = valor, deixar o Go deduzir o tipo, e usar :=.
  • O valor zero: toda variável começa com um valor, nunca com lixo.
  • Atribuir com =, declarar várias de uma vez e trocar dois valores.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Três jeitos de declarar

package main

import "fmt"

func main() {
	var nome string = "Ana"
	var idade int = 30
	var cidade = "Recife" // o Go deduz o tipo: string
	pais := "Brasil"      // declaração curta, só dentro de funções
	fmt.Println(nome, idade, cidade, pais)

	idade = 31 // muda o valor: sem var, sem :=
	fmt.Println("ano que vem:", idade)
}
$ go run main.go
Ana 30 Recife Brasil
ano que vem: 31
var
“vou criar uma variável”.
nome
o nome da caixa.
string
o tipo: texto.
= "Ana"
o valor inicial.

Quando há valor inicial, o tipo pode sair: var cidade = "Recife" vira string sozinho. A forma curta pais := "Brasil" faz o mesmo sem o var e é a mais usada dentro de funções. Para mudar o valor depois, use só =.

2. O valor zero

Variável declarada sem valor não fica “vazia” nem com lixo: ganha o valor zero do tipo. 0 para números, false para bool e "" (texto vazio) para string. O %q mostra o texto entre aspas, para dar para ver que ele está vazio:

package main

import "fmt"

func main() {
	var contador int
	var preco float64
	var ativo bool
	var apelido string
	fmt.Println(contador, preco, ativo)
	fmt.Printf("apelido: %q\n", apelido)

	x, y := 10, 20
	x, y = y, x // troca os valores numa linha só
	fmt.Println("x =", x, "y =", y)
}
$ go run main.go

3. Nomes

Nomes começam com letra (ou _) e podem ter números. O costume em Go é camelCase: precoTotal, nomeCompleto. Maiúscula no começo tem significado especial (exportar, no Nível 2), então variáveis locais começam com minúscula.

Quando dá errado

:= duas vezes na mesma variável

O := cria. Para mudar o valor de uma variável que já existe, use =:

package main

import "fmt"

func main() {
	idade := 30
	idade := 31
	fmt.Println(idade)
}
$ go run main.go
# command-line-arguments
./main.go:7:8: no new variables on left side of :=
Valor do tipo errado

Uma caixa de int não aceita texto:

package main

import "fmt"

func main() {
	var idade int = 30
	idade = "trinta"
	fmt.Println(idade)
}
$ go run main.go
# command-line-arguments
./main.go:7:10: cannot use "trinta" (untyped string constant) as int value in assignment
:= fora de função

Fora de funções, só vale var. A forma curta ali é erro de sintaxe:

package main

import "fmt"

total := 10

func main() {
	fmt.Println(total)
}
$ go run main.go
# command-line-arguments
./main.go:5:1: syntax error: non-declaration statement outside function body

Missão: troque os valores de a e b numa linha só (a, b = b, a), para o programa escrever a = 2 b = 1.

package main

import "fmt"

func main() {
	a, b := 1, 2
	// troque aqui
	fmt.Println("a =", a, "b =", b)
}

package main

import "fmt"

func main() {
	a, b := 1, 2
	a, b = b, a
	fmt.Println("a =", a, "b =", b)
}

a = 2 b = 1

Resumo

  • var x tipo = valor, var x = valor ou x := valor (só em funções).
  • Variável sem valor começa com o valor zero do tipo.
  • := cria; = muda.
