Múltiplos retornos

Em Go uma função pode devolver vários valores de uma vez. Isso é usado o tempo todo: quociente e resto, menor e maior e, principalmente, resultado e erro. É por isso que você vai ver valor, err := … em quase todo programa Go.

Você vai aprender
  • Declarar func f() (int, int) e receber com a, b := f().
  • Retornos nomeados e o return “nu”.
  • Ignorar um valor com _ e o padrão valor, err.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Vários valores

package main

import "fmt"

func dividir(a, b int) (int, int) {
	return a / b, a % b
}

func minMax(nums []int) (menor, maior int) {
	menor, maior = nums[0], nums[0]
	for _, n := range nums {
		if n < menor {
			menor = n
		}
		if n > maior {
			maior = n
		}
	}
	return // retorno "nu": devolve menor e maior
}

func main() {
	q, r := dividir(17, 5)
	fmt.Println("quociente:", q, "resto:", r)

	_, resto := dividir(10, 3)
	fmt.Println("só o resto:", resto)

	lo, hi := minMax([]int{4, 9, 1, 7})
	fmt.Println("menor:", lo, "maior:", hi)
}
$ go run main.go
quociente: 3 resto: 2
só o resto: 1
menor: 1 maior: 9
(int, int)
a função devolve dois inteiros.
return a / b, a % b
os dois valores, separados por vírgula.
q, r := dividir(17, 5)
recebe os dois, na mesma ordem.

Em minMax, os retornos têm nome (menor, maior): eles já começam com o valor zero, e um return sozinho devolve o que estiver neles. Use isso em funções curtas; nas longas, prefira escrever o que volta. O _ descarta um valor que você não quer.

2. O par (resultado, erro)

O uso mais importante: muitas funções devolvem o resultado e um error. Se err não for nil, algo deu errado e o resultado não deve ser usado:

package main

import (
	"fmt"
	"strconv"
)

func main() {
	for _, s := range []string{"10", "dez", "7"} {
		n, err := strconv.Atoi(s)
		if err != nil {
			fmt.Println("pulei", s, "->", err)
			continue
		}
		fmt.Println(s, "vezes 2 =", n*2)
	}
}
$ go run main.go
10 vezes 2 = 20
pulei dez -> strconv.Atoi: parsing "dez": invalid syntax
7 vezes 2 = 14

Quando dá errado

Receber só um dos dois valores 
package main

import "fmt"

func dividir(a, b int) (int, int) {
	return a / b, a % b
}

func main() {
	q := dividir(17, 5)
	fmt.Println(q)
}
$ go run main.go
# command-line-arguments
./main.go:10:7: assignment mismatch: 1 variable but dividir returns 2 values

Receba os dois (q, r :=) ou descarte um (q, _ :=).

Devolver valores a menos 
package main

import "fmt"

func dividir(a, b int) (int, int) {
	return a / b
}

func main() {
	fmt.Println(dividir(17, 5))
}
$ go run main.go
# command-line-arguments
./main.go:6:9: not enough return values
	have (int)
	want (int, int)

Referência rápida

Você escreveO que faz
func f() (int, error)Devolve dois valores.
a, b := f()Recebe os dois.
a, _ := f()Descarta o segundo.
func f() (x, y int) { …; return }Retornos nomeados e return nu.
v, err := f(); if err != nil { … }O padrão resultado + erro.

Exercícios

1. Receber

Complete para receber os dois valores:

q r := dividir(9, 2)

2. Descartar

Complete para jogar fora o primeiro:

, r := dividir(9, 2)

3. O que é o _ em _, r := dividir(9, 2)?

4. Depois de n, err := strconv.Atoi(s), quando você pode confiar em n?

Missão: escreva func estatisticas(nums []int) (soma int, media float64), que devolve a soma e a média. Para 2, 4 e 9, a saída deve ser soma: 15 média: 5.

package main

import "fmt"

func main() {
	nums := []int{2, 4, 9}
	fmt.Println(nums)
}

package main

import "fmt"

func estatisticas(nums []int) (soma int, media float64) {
	for _, n := range nums {
		soma += n
	}
	media = float64(soma) / float64(len(nums))
	return soma, media
}

func main() {
	nums := []int{2, 4, 9}
	s, m := estatisticas(nums)
	fmt.Println("soma:", s, "média:", m)
}

soma: 15 média: 5

Resumo

  • Funções podem devolver vários valores: func f() (int, int).
  • Receba todos ou descarte com _.
  • O par valor, err é o padrão de Go para operações que podem falhar.
