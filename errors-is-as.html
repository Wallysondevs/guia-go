errors.Is e errors.As

Na aula Erros você embrulhou erros com %w. Agora vem o outro lado: abrir o embrulho para descobrir qual erro foi. errors.Is pergunta “é este erro?”; errors.As pergunta “é deste tipo?” e entrega os detalhes.

Você vai aprender
  • Criar erros sentinela (var ErrX = errors.New(…)) e testá-los com errors.Is, mesmo embrulhados.
  • Criar um tipo de erro com o método Error() string e extraí-lo com errors.As.
  • Usar os erros da biblioteca padrão: fs.ErrNotExist e *fs.PathError.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. errors.Is: é este erro?

Um erro sentinela é uma variável de erro conhecida, que quem chama pode comparar. O errors.Is procura o sentinela mesmo dentro de embrulhos feitos com %w (o == não acharia):

package main

import (
	"errors"
	"fmt"
	"io/fs"
	"os"
)

var ErrSemEstoque = errors.New("produto sem estoque")

func vender(produto string, estoque map[string]int) error {
	if estoque[produto] == 0 {
		return fmt.Errorf("vender %q: %w", produto, ErrSemEstoque)
	}
	estoque[produto]--
	return nil
}

func main() {
	estoque := map[string]int{"café": 1}
	for _, p := range []string{"café", "café"} {
		err := vender(p, estoque)
		if errors.Is(err, ErrSemEstoque) {
			fmt.Println("avise o cliente:", err)
		} else if err == nil {
			fmt.Println("vendido:", p)
		}
	}

	_, err := os.Open("nao-existe.txt")
	fmt.Println(err)
	fmt.Println("não existe?", errors.Is(err, fs.ErrNotExist))
}
$ go run main.go
vendido: café
avise o cliente: vender "café": produto sem estoque
open nao-existe.txt: no such file or directory
não existe? true

2. errors.As: é deste tipo?

Quando o erro carrega dados (qual campo, qual arquivo), crie um tipo com o método Error() string. O errors.As procura um erro daquele tipo no embrulho e o copia para a sua variável:

package main

import (
	"errors"
	"fmt"
	"io/fs"
	"os"
)

type ErroValidacao struct {
	Campo  string
	Motivo string
}

func (e *ErroValidacao) Error() string {
	return e.Campo + ": " + e.Motivo
}

func cadastrar(nome string, idade int) error {
	if idade < 0 {
		return fmt.Errorf("cadastro de %s: %w", nome, &ErroValidacao{"idade", "não pode ser negativa"})
	}
	return nil
}

func main() {
	err := cadastrar("Rui", -3)
	fmt.Println(err)

	var ev *ErroValidacao
	if errors.As(err, &ev) {
		fmt.Println("campo com problema:", ev.Campo)
	}

	_, err = os.ReadFile("sumiu.txt")
	var pe *fs.PathError
	if errors.As(err, &pe) {
		fmt.Println("operação:", pe.Op, "| caminho:", pe.Path, "| erro:", pe.Err)
	}
}
$ go run main.go
cadastro de Rui: idade: não pode ser negativa
campo com problema: idade
operação: open | caminho: sumiu.txt | erro: no such file or directory
var ev *ErroValidacao
a variável que vai receber o erro encontrado.
errors.As(err, &ev)
passa o endereço dela; devolve true se achou.
ev.Campo
os detalhes, agora acessíveis.

Quando dá errado

== não abre o embrulho, e %v não embrulha

Isto compila e roda, mas mostra duas armadilhas: comparar com == um erro embrulhado dá false, e um erro “embrulhado” com %v vira só texto, sem o original dentro:

package main

import (
	"errors"
	"fmt"
)

var ErrSemEstoque = errors.New("produto sem estoque")

func main() {
	err := fmt.Errorf("vender: %w", ErrSemEstoque)
	fmt.Println("com ==:", err == ErrSemEstoque)
	fmt.Println("com errors.Is:", errors.Is(err, ErrSemEstoque))

	semW := fmt.Errorf("vender: %v", ErrSemEstoque)
	fmt.Println("embrulhado com %v:", errors.Is(semW, ErrSemEstoque))
}
$ go run main.go
com ==: false
com errors.Is: true
embrulhado com %v: false
errors.As sem o &

O segundo argumento precisa ser um ponteiro. O go vet avisa:

package main

import (
	"errors"
	"fmt"
)

type ErroValidacao struct{ Campo string }

func (e *ErroValidacao) Error() string { return e.Campo }

func main() {
	err := fmt.Errorf("x: %w", &ErroValidacao{"idade"})
	var ev ErroValidacao
	fmt.Println(errors.As(err, ev))
}
$ go vet main.go
main.go:15:14: second argument to errors.As must be a non-nil pointer to either a type that implements error, or to any interface type

package main

import (
	"fmt"
	"os"
)

func main() {
	_, err := os.ReadFile("config-que-nao-existe.json")
	if err != nil {
		fmt.Println("outro erro:", err)
	}
}

package main

import (
	"errors"
	"fmt"
	"io/fs"
	"os"
)

func main() {
	_, err := os.ReadFile("config-que-nao-existe.json")
	if errors.Is(err, fs.ErrNotExist) {
		fmt.Println("arquivo não encontrado")
	} else if err != nil {
		fmt.Println("outro erro:", err)
	}
}

Resumo

  • errors.Is reconhece um erro sentinela, mesmo embrulhado com %w.
  • errors.As acha um tipo de erro e entrega os detalhes.
  • Use %w (não %v) para embrulhar.
