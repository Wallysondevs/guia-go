JSON (encoding/json)

JSON é o formato de texto que as APIs usam para trocar dados. O pacote encoding/json transforma uma struct em JSON (Marshal) e JSON em struct (Unmarshal). As tags entre crases dizem o nome de cada campo no JSON.

Você vai aprender
  • Gerar JSON com json.Marshal e json.MarshalIndent.
  • Controlar os nomes com tags: `json:"nome"`, omitempty e "-".
  • Ler JSON com json.Unmarshal para struct ou map[string]any, e tratar JSON inválido.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. De struct para JSON

package main

import (
	"encoding/json"
	"fmt"
)

type Produto struct {
	Nome     string   `json:"nome"`
	Preco    float64  `json:"preco"`
	Tags     []string `json:"tags,omitempty"`
	Estoque  int      `json:"-"`
	Destaque bool     `json:"destaque"`
}

func main() {
	p := Produto{Nome: "Café", Preco: 18.9, Estoque: 3}
	b, err := json.Marshal(p)
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(string(b))

	lista := []Produto{p, {Nome: "Pão", Preco: 0.75, Tags: []string{"padaria"}, Destaque: true}}
	bonito, _ := json.MarshalIndent(lista, "", "  ")
	fmt.Println(string(bonito))
}
$ go run main.go
{"nome":"Café","preco":18.9,"destaque":false}
[
  {
    "nome": "Café",
    "preco": 18.9,
    "destaque": false
  },
  {
    "nome": "Pão",
    "preco": 0.75,
    "tags": [
      "padaria"
    ],
    "destaque": true
  }
]
`json:"nome"`
a tag: no JSON o campo se chama nome.
omitempty
some do JSON quando está vazio (o Café não tem tags).
`json:"-"`
nunca entra no JSON (o Estoque).

Só campos exportados (com maiúscula) entram no JSON. O Marshal devolve bytes: por isso o string(b).

2. De JSON para struct (ou map)

O Unmarshal recebe os bytes e o endereço da variável. Campos do JSON que a struct não tem (obs) são ignorados. Num map[string]any cabe tudo, mas números viram float64:

package main

import (
	"encoding/json"
	"fmt"
)

type Pedido struct {
	ID      int      `json:"id"`
	Cliente string   `json:"cliente"`
	Itens   []string `json:"itens"`
}

func main() {
	entrada := `{"id": 7, "cliente": "Ana", "itens": ["café", "pão"], "obs": "sem açúcar"}`
	var p Pedido
	if err := json.Unmarshal([]byte(entrada), &p); err != nil {
		fmt.Println("erro:", err)
		return
	}
	fmt.Printf("%+v\n", p)

	var solto map[string]any
	json.Unmarshal([]byte(entrada), &solto)
	fmt.Println(solto["obs"], solto["id"])
	fmt.Printf("%T\n", solto["id"])
}
$ go run main.go
{ID:7 Cliente:Ana Itens:[café pão]}
sem açúcar 7
float64

Quando dá errado

JSON inválido ou do tipo errado

Uma vírgula sobrando e um texto onde se esperava número:

package main

import (
	"encoding/json"
	"fmt"
)

type Pedido struct {
	ID int `json:"id"`
}

func main() {
	var p Pedido
	fmt.Println(json.Unmarshal([]byte(`{"id": 7,}`), &p))
	fmt.Println(json.Unmarshal([]byte(`{"id": "sete"}`), &p))
}
$ go run main.go
invalid character '}' looking for beginning of object key string
json: cannot unmarshal string into Go struct field Pedido.id of type int
Campo minúsculo some do JSON

Sem mensagem de erro: o campo nome não é exportado, e o encoding/json simplesmente não o vê:

package main

import (
	"encoding/json"
	"fmt"
)

type Pessoa struct {
	nome  string
	Idade int
}

func main() {
	b, _ := json.Marshal(Pessoa{nome: "Ana", Idade: 30})
	fmt.Println(string(b))
}
$ go run main.go
{"Idade":30}

Resumo

  • json.Marshal gera JSON; json.Unmarshal lê (passe o endereço).
  • Tags controlam os nomes; omitempty e "-" tiram campos.
  • Só campos exportados entram no JSON; confira o err do Unmarshal.
