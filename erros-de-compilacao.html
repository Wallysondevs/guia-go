Lendo erros de compilação

O compilador do Go é exigente, e isso é bom: ele pega muitos erros antes de o programa rodar. Nesta aula você aprende a ler a mensagem, que sempre diz o arquivo, a linha e a coluna, e conhece os erros que todo iniciante vê na primeira semana.

Você vai aprender
  • Ler ./main.go:6:2: mensagem: arquivo, linha, coluna e o que deu errado.
  • Os erros típicos: variável e import não usados, nome indefinido, tipo errado, sintaxe.
  • Por que o Go trata variável não usada como erro, e não como aviso.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. A anatomia do erro

Este programa cria uma variável e nunca a usa. Em Go, isso não compila:

package main

import "fmt"

func main() {
	idade := 30
	fmt.Println("Olá!")
}
$ go run main.go
# command-line-arguments
./main.go:6:2: declared and not used: idade
# command-line-arguments
o pacote que estava sendo compilado (um arquivo solto passado ao go run ganha esse nome).
./main.go
o arquivo.
:6:2
linha 6, coluna 2.
declared and not used: idade
a mensagem: “declarada e não usada: idade”.

Variável sem uso costuma ser um esquecimento ou um erro de digitação. Por isso o Go recusa o programa em vez de só avisar. A saída é usá-la ou apagá-la.

2. Import não usado

Pelo mesmo motivo, importar um pacote e não usar também é erro:

package main

import (
	"fmt"
	"os"
)

func main() {
	fmt.Println("Olá!")
}
$ go run main.go
# command-line-arguments
./main.go:5:2: "os" imported and not used

3. undefined: nome que não existe

Erro de digitação no nome de uma variável ou função. Aqui nome virou nomee:

package main

import "fmt"

func main() {
	nome := "Ana"
	fmt.Println("Olá,", nomee)
}
$ go run main.go
# command-line-arguments
./main.go:6:2: declared and not used: nome
./main.go:7:23: undefined: nomee

Vieram dois erros de um engano só: como o Println usa nomee, a variável nome ficou sem uso (linha 6), e nomee não existe (linha 7, coluna 23). Corrigindo a digitação, os dois somem.

4. Tipos que não combinam

Go não mistura texto com número sozinho. Somar uma string com um int não compila:

package main

import "fmt"

func main() {
	idade := 30
	fmt.Println("Idade: " + idade)
}
$ go run main.go
# command-line-arguments
./main.go:7:14: invalid operation: "Idade: " + idade (mismatched types untyped string and int)

A aula Conversão de Tipos mostra como transformar um no outro.

5. Vários erros de uma vez

O compilador lista vários erros de uma vez. Corrija do primeiro para o último: às vezes um erro causa os seguintes.

package main

import (
	"fmt"
	"strings"
)

func main() {
	x := 1
	y := 2
	fmt.Println("soma:", x+z)
}
$ go run main.go
# command-line-arguments
./main.go:5:2: "strings" imported and not used
./main.go:10:2: declared and not used: y
./main.go:11:25: undefined: z

Quando dá errado

Erro de sintaxe: parêntese aberto

Quando falta um parêntese, o compilador para no primeiro lugar em que a frase “não faz sentido”:

package main

import "fmt"

func main() {
	fmt.Println("faltou fechar o parêntese"
}
$ go run main.go
# command-line-arguments
./main.go:6:42: syntax error: unexpected newline in argument list; possibly missing comma or )

O compilador apontou a linha 6, coluna 42: bem no fim da linha, onde ele esperava uma vírgula ou o ) e encontrou a quebra de linha. A própria mensagem sugere: possibly missing comma or ).

Chave que nunca fecha

Se falta a última }, o arquivo acaba antes da hora:

package main

import "fmt"

func main() {
	fmt.Println("faltou fechar a chave")
$ go run main.go
# command-line-arguments
./main.go:7:1: syntax error: unexpected EOF, expected }

unexpected EOF quer dizer “o arquivo acabou de repente” (end of file).

Referência rápida

Você escreveO que faz
declared and not used: xVariável criada e nunca usada: use ou apague.
"os" imported and not usedImport sobrando: apague a linha.
undefined: xNome que não existe (digitação? outro arquivo?).
mismatched typesTipos diferentes na mesma conta.
syntax error: unexpected …Faltou ou sobrou parêntese, chave, vírgula.

Resumo

  • O erro diz arquivo, linha e coluna: ./main.go:6:2:.
  • Variável e import sem uso são erros, não avisos.
  • undefined é nome que não existe; mismatched types é mistura de tipos.
  • Corrija do primeiro erro para o último.
