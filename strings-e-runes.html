Strings e Runes

Uma string em Go é uma sequência de bytes em UTF-8, que não muda depois de criada. Letras sem acento ocupam um byte; á, ç e ã ocupam dois. Por isso existe a rune: um caractere Unicode inteiro. Saber isso evita o bug clássico de cortar um acento ao meio.

Você vai aprender
  • A diferença entre len(s) (bytes) e o número de caracteres.
  • rune, o range por caracteres e a conversão []rune(s).
  • As funções do pacote strings, o strings.Builder e as strings cruas com crase.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Bytes, runes e range

package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	s := "Olá, Go"
	fmt.Println(len(s), utf8.RuneCountInString(s))
	fmt.Println(s[0], string(s[0]))
	fmt.Println(s[:3])

	for i, r := range "ação" {
		fmt.Printf("%d:%c(%d) ", i, r, r)
	}
	fmt.Println()

	runas := []rune("ação")
	fmt.Println(len(runas), string(runas[1]))
}
$ go run main.go
8 7
79 O
Ol�
0:a(97) 1:ç(231) 3:ã(227) 5:o(111)

"Olá, Go" tem 7 caracteres mas 8 bytes, porque o á usa dois. s[0] é um byte (79, o O). E s[:3] corta 3 bytes: o O, o l e só a primeira metade do á, que o terminal mostra como � (veja “Quando dá errado”). O range anda de caractere em caractere: em "ação", os índices pulam de 1 para 3 porque o ç ocupa os bytes 1 e 2. Para trabalhar com caracteres por posição, converta para []rune.

2. O pacote strings

package main

import (
	"fmt"
	"strings"
)

func main() {
	frase := "  Go é simples e Go é rápido  "
	limpa := strings.TrimSpace(frase)
	fmt.Printf("%q\n", limpa)
	fmt.Println(strings.ToUpper(limpa))
	fmt.Println(strings.Contains(limpa, "rápido"), strings.Count(limpa, "Go"))
	fmt.Println(strings.Replace(limpa, "Go", "Golang", 1))
	fmt.Println(strings.Split("a,b,c", ","))
	fmt.Println(strings.Join([]string{"2026", "11", "21"}, "-"))
	fmt.Println(strings.HasPrefix(limpa, "Go"), strings.Index(limpa, "simples"))
	fmt.Println(strings.Repeat("=", 10))
}
$ go run main.go
"Go é simples e Go é rápido"

Golang é simples e Go é rápido
[a b c]

3. Montando texto e strings cruas

Strings não mudam: para “trocar” uma letra, você monta outra string. Para juntar muitos pedaços, o strings.Builder é eficiente. E texto entre crases é “cru”: a barra invertida não é escape, bom para caminhos do Windows e expressões regulares:

package main

import (
	"fmt"
	"strings"
)

func main() {
	var b strings.Builder
	for i := 3; i > 0; i-- {
		fmt.Fprintf(&b, "%d... ", i)
	}
	b.WriteString("já!")
	fmt.Println(b.String())

	s := "texto"
	// s[0] = 'T' não compila: strings não mudam
	s = "T" + s[1:]
	fmt.Println(s)
	fmt.Println("caminho: C:\\pasta", `cru: C:\pasta\n sem escape`)
}
$ go run main.go
3... 2... 1... já!
Texto
caminho: C:\pasta cru: C:\pasta\n sem escape

Quando dá errado

Tentar mudar uma letra 
package main

import "fmt"

func main() {
	s := "texto"
	s[0] = 'T'
	fmt.Println(s)
}
$ go run main.go
# command-line-arguments
./main.go:7:2: cannot assign to s[0] (neither addressable nor a map index expression)
Cortar no meio de um acento

Isto compila e roda, mas s[:2] pega 2 bytes: o a e só a primeira metade do ç. O terminal mostra um caractere quebrado. Com []rune, o corte é por caracteres:

package main

import "fmt"

func main() {
	s := "ação"
	fmt.Println(s[:2])
	fmt.Println(string([]rune(s)[:2]))
}
$ go run main.go
a�
aç

Referência rápida

Você escreveO que faz
len(s)Tamanho em bytes.
utf8.RuneCountInString(s)Número de caracteres.
for i, r := range sPercorre caracteres (r é rune).
[]rune(s), string(runas)Texto ↔ lista de caracteres.
strings.ToUpper, Contains, Split, Join, TrimSpaceFunções do pacote strings.
`texto cru`Sem escapes (\n fica literal).

Missão: escreva quantos bytes e quantos caracteres tem a palavra coração. A saída deve ser bytes: 9 caracteres: 7.

package main

import "fmt"

func main() {
	palavra := "coração"
	fmt.Println("bytes:", len(palavra))
}

package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	palavra := "coração"
	fmt.Println("bytes:", len(palavra), "caracteres:", utf8.RuneCountInString(palavra))
}

bytes: 9 caracteres: 7

Missão: use strings.Split para separar "Ana;Rui;Bia" pelo ; e strings.Join para juntar com " e ". A saída deve ser Ana e Rui e Bia.

package main

import "fmt"

func main() {
	nomes := "Ana;Rui;Bia"
	fmt.Println(nomes)
}

package main

import (
	"fmt"
	"strings"
)

func main() {
	nomes := "Ana;Rui;Bia"
	partes := strings.Split(nomes, ";")
	fmt.Println(strings.Join(partes, " e "))
}

Ana e Rui e Bia

Resumo

  • String é uma sequência de bytes UTF-8 que não muda.
  • len conta bytes; range e []rune trabalham com caracteres.
  • O pacote strings tem quase tudo; crases fazem strings cruas.
