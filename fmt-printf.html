Formatando com fmt.Printf

O Println escreve valores um depois do outro. O Printf deixa você montar a frase com buracos (os verbos, como %d e %s) e escolher casas decimais, largura e alinhamento. O Sprintf faz o mesmo, mas devolve o texto em vez de escrever.

Você vai aprender
  • Os verbos mais usados: %d, %s, %f, %v, %T, %q, %t.
  • Casas decimais (%.2f), largura (%8s), alinhamento à esquerda (%-8s) e zeros (%05d).
  • Montar texto com fmt.Sprintf e mostrar structs com %+v.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Os verbos

Cada % na frase é trocado pelo próximo valor da lista. O Printf não pula linha sozinho: ponha \n no fim.

package main

import "fmt"

func main() {
	nome := "Ana"
	idade := 30
	altura := 1.6543
	fmt.Printf("%s tem %d anos e %.2f m\n", nome, idade, altura)
	fmt.Printf("%v | %+v | %T\n", idade, idade, altura)
	fmt.Printf("%q\n", nome)
	fmt.Printf("%t\n", idade > 18)
	fmt.Printf("%x %o %b\n", 255, 8, 5)
	fmt.Printf("%c %U\n", 'ç', 'ç')
	fmt.Printf("100%%\n")
}

2. Largura e alinhamento

Um número entre o % e a letra é a largura mínima. Com -, o texto encosta na esquerda; com 0, os números ganham zeros. Isso monta tabelas alinhadas:

package main

import "fmt"

func main() {
	fmt.Printf("[%8s]\n", "Go")
	fmt.Printf("[%-8s]\n", "Go")
	fmt.Printf("[%5d]\n", 42)
	fmt.Printf("[%05d]\n", 42)
	fmt.Printf("[%8.3f]\n", 3.14159)

	fmt.Printf("%-10s %6s\n", "produto", "preço")
	fmt.Printf("%-10s %6.2f\n", "café", 4.5)
	fmt.Printf("%-10s %6.2f\n", "pão", 0.75)
}
$ go run main.go
[      Go]
[Go      ]
[   42]
[00042]
[   3.142]
produto     preço
café         4.50
pão          0.75

Repare que pão e café ficaram alinhados mesmo com acento: a largura do Printf conta caracteres (runes), não bytes.

3. Sprintf e structs

O Sprintf devolve o texto pronto, para guardar numa variável. E para structs (aula Structs), %+v mostra o nome dos campos e %#v mostra como se escreve em Go:

package main

import "fmt"

func main() {
	msg := fmt.Sprintf("%s tem %d anos", "Ana", 30)
	fmt.Println(msg)
	fmt.Println(len(msg))

	type ponto struct{ X, Y int }
	p := ponto{1, 2}
	fmt.Printf("%v\n%+v\n%#v\n", p, p, p)
}
$ go run main.go
Ana tem 30 anos
15
{1 2}
{X:1 Y:2}
main.ponto{X:1, Y:2}

Quando dá errado

Verbo e valor que não combinam

Aqui falta um valor, um verbo pede número e recebe texto, e sobra um valor. O programa compila e roda, e o Printf marca os problemas na própria saída com %!. Já o go vet pega os três antes de rodar:

package main

import "fmt"

func main() {
	fmt.Printf("%s tem %d anos\n", "Ana")
	fmt.Printf("%d\n", "trinta")
	fmt.Printf("oi\n", 1)
}
$ go run main.go
Ana tem %!d(MISSING) anos
%!d(string=trinta)
oi
%!(EXTRA int=1)
$ go vet main.go
main.go:6:21: fmt.Printf format %d reads arg #2, but call has 1 arg
main.go:7:14: fmt.Printf format %d has arg "trinta" of wrong type string
main.go:8:21: fmt.Printf call has arguments but no formatting directives

Leia %!d(MISSING) como “faltou o valor do %d”, %!d(string=trinta) como “o %d recebeu uma string” e %!(EXTRA int=1) como “sobrou um valor”.

Exercícios

1. Inteiro

Complete o verbo para um inteiro:

fmt.Printf("idade: \n", 30)

2. Duas casas

Complete para mostrar 4.50:

fmt.Printf("\n", 4.5)

3. Devolver texto

Complete para guardar o texto numa variável:

msg := fmt.("%s!", "Oi")

4. O que %v faz?

5. Por que o Printf abaixo escreve tudo na mesma linha? fmt.Printf("a"); fmt.Printf("b")

Missão: use Printf com %s e %.2f para escrever café custa R$ 4.50.

package main

import "fmt"

func main() {
	produto := "café"
	preco := 4.5
	fmt.Println(produto, preco)
}

package main

import "fmt"

func main() {
	produto := "café"
	preco := 4.5
	fmt.Printf("%s custa R$ %.2f\n", produto, preco)
}

café custa R$ 4.50

Missão: use fmt.Sprintf para montar a frase Ana tem 30 anos numa variável msg e escreva msg com Println.

package main

import "fmt"

func main() {
	nome, idade := "Ana", 30
	msg := ""
	fmt.Println(msg)
}

package main

import "fmt"

func main() {
	nome, idade := "Ana", 30
	msg := fmt.Sprintf("%s tem %d anos", nome, idade)
	fmt.Println(msg)
}

Ana tem 30 anos

Resumo

  • Printf troca cada verbo pelo próximo valor; ponha \n no fim.
  • %d, %s, %.2f, %v, %T, %q são os mais usados.
  • Largura e - alinham colunas; Sprintf devolve o texto.
  • Verbos errados aparecem como %!; o go vet avisa antes.
