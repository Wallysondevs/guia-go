Testes (go test)

Um teste é um programa que confere outro programa. Em Go isso vem de fábrica: escreva funções TestAlgo num arquivo terminado em _test.go e rode go test. Sem bibliotecas extras, sem configuração.

Você vai aprender
  • As regras: arquivo _test.go, função func TestXxx(t *testing.T).
  • Avisar falhas com t.Errorf (continua) e t.Fatalf (para o teste).
  • Rodar com go test, -v e -run, e ler a saída de uma falha.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. O código e o teste

O pacote calc, num módulo de mesmo nome, tem duas funções. O teste fica ao lado, em calc_test.go, no mesmo pacote:

package calc

// Soma devolve a soma de todos os números.
func Soma(nums ...int) int {
	total := 0
	for _, n := range nums {
		total += n
	}
	return total
}

// Media devolve a média; com lista vazia, devolve 0.
func Media(nums ...int) float64 {
	if len(nums) == 0 {
		return 0
	}
	return float64(Soma(nums...)) / float64(len(nums))
}
package calc

import "testing"

func TestSoma(t *testing.T) {
	got := Soma(1, 2, 3)
	want := 6
	if got != want {
		t.Errorf("Soma(1, 2, 3) = %d; queria %d", got, want)
	}
}

func TestMedia(t *testing.T) {
	if got := Media(2, 4); got != 3 {
		t.Errorf("Media(2, 4) = %v; queria 3", got)
	}
}
$ go test

só arquivos _test.go são lidos pelo go test (e ficam fora do executável).
func TestSoma
começa com Test e uma maiúscula.
t *testing.T
o “caderno” do teste: é por ele que você avisa as falhas.
t.Errorf(…)
marca o teste como falho, com a mensagem, e continua.

Quando tudo passa, o go test mostra uma linha só: ok, o pacote e o tempo. Com -v (de verbose) ele mostra cada teste, e com -run roda só os testes cujo nome casa com o padrão.

2. Quando um teste falha

Agora o Media tem um defeito: divide por len(nums)+1. O teste pega:

$ go test
--- FAIL: TestMedia (0.00s)
    calc_test.go:15: Media(2, 4) = 2; queria 3
FAIL
exit status 1
FAIL	calc	0.002s

A saída diz o arquivo e a linha do t.Errorf (calc_test.go:15), a mensagem que você escreveu e, no fim, FAIL. Por isso vale escrever mensagens no formato “recebi X; queria Y”.

Quando dá errado

Teste com nome minúsculo não roda

testSoma não começa com Test maiúsculo, então o go test nem o vê: avisa no tests to run e, mesmo assim, termina com ok. O go vet também ficou calado. Por isso vale rodar com -v e conferir se o seu teste aparece na lista.

package calc

import "testing"

func testSoma(t *testing.T) {
	if Soma(1, 1) != 2 {
		t.Error("errado")
	}
}
$ go test -v
testing: warning: no tests to run
PASS
ok  	calc	0.002s
$ go vet

Resumo

  • Testes ficam em _test.go, em funções TestXxx(t *testing.T).
  • t.Errorf marca falha; a saída mostra arquivo, linha e mensagem.
  • go test, -v e -run.
