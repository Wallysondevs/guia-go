Tipos básicos

Todo valor em Go tem um tipo, e o tipo diz o que dá para fazer com ele. Nesta aula você conhece os tipos básicos, vê o tipo de cada valor com %T, os limites dos inteiros e duas surpresas: a divisão inteira e o 0.1 + 0.2.

Você vai aprender
  • Os tipos do dia a dia: int, float64, string, bool.
  • rune (um caractere Unicode) e byte (um byte).
  • Os tamanhos dos inteiros, a divisão inteira, o resto (%) e o estouro.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Os tipos e o %T

O verbo %T do Printf escreve o tipo do valor; %v escreve o valor (aula fmt.Printf):

package main

import "fmt"

func main() {
	var inteiro int = 42
	var real float64 = 3.75
	var texto string = "Go"
	var verdade bool = true
	var letra rune = 'G'
	var b byte = 'o'

	fmt.Printf("%v é %T\n", inteiro, inteiro)
	fmt.Printf("%v é %T\n", real, real)
	fmt.Printf("%v é %T\n", texto, texto)
	fmt.Printf("%v é %T\n", verdade, verdade)
	fmt.Printf("%v é %T\n", letra, letra)
	fmt.Printf("%v é %T\n", b, b)
}
$ go run main.go
42 é int
3.75 é float64
Go é string
true é bool
71 é int32
111 é uint8

Repare: rune aparece como int32 e byte como uint8. São apelidos: um caractere é guardado como o número dele na tabela Unicode (o G é 71, o o é 111).

2. Tamanhos, divisão e resto

Existem inteiros de 8, 16, 32 e 64 bits, com sinal (int8…int64) e sem sinal (uint8…uint64). O pacote math tem os limites:

package main

import (
	"fmt"
	"math"
)

func main() {
	fmt.Println("int8:", math.MinInt8, "a", math.MaxInt8)
	fmt.Println("uint8:", 0, "a", math.MaxUint8)
	fmt.Println("int32:", math.MinInt32, "a", math.MaxInt32)
	fmt.Println("int64 máx:", math.MaxInt64)
	fmt.Println("7 / 2 =", 7/2, "  7 % 2 =", 7%2)
	fmt.Println("7.0 / 2 =", 7.0/2)
	a, b := 0.1, 0.2
	fmt.Println("0.1 + 0.2 =", a+b)
}
$ go run main.go
int8: -128 a 127
uint8: 0 a 255
int32: -2147483648 a 2147483647
int64 máx: 9223372036854775807
7 / 2 = 3   7 % 2 = 1
7.0 / 2 = 3.5
0.1 + 0.2 = 0.30000000000000004

Três coisas para guardar: inteiro dividido por inteiro dá inteiro (7/2 é 3); o % dá o resto; e números com vírgula são aproximados no computador, por isso 0.1 + 0.2, com os valores guardados em variáveis float64, não dá exatamente 0.3. (Se você escrever a conta direto com números, 0.1+0.2, o compilador faz a conta exata antes e escreve 0.3.) Para dinheiro, guarde centavos em int.

3. Estouro

Quando a conta passa do limite do tipo, o valor “dá a volta”. Um int8 vai até 127; somando 1, vira -128:

package main

import "fmt"

func main() {
	var pequeno int8 = 127
	pequeno++
	fmt.Println("127 + 1 em int8 =", pequeno)
}
$ go run main.go
127 + 1 em int8 = -128

Quando dá errado

Valor que não cabe no tipo

Se o compilador já sabe que o valor não cabe, ele recusa:

package main

import "fmt"

func main() {
	var pequeno int8 = 200
	fmt.Println(pequeno)
}
$ go run main.go
# command-line-arguments
./main.go:6:21: cannot use 200 (untyped int constant) as int8 value in variable declaration (overflows)
Misturar int com float64

Go não converte sozinho entre tipos numéricos:

package main

import "fmt"

func main() {
	var a int = 10
	var b float64 = 2.5
	fmt.Println(a * b)
}
$ go run main.go
# command-line-arguments
./main.go:8:14: invalid operation: a * b (mismatched types int and float64)

A solução, float64(a) * b, está na aula Conversão de Tipos.

import "fmt"

Missão: mostre o quociente e o resto de 17 dividido por 5, com / e %. A saída deve ser 17 / 5 = 3 resto 2.

package main

import "fmt"

func main() {
	a, b := 17, 5
	fmt.Println(a, "/", b, "=")
}

package main

import "fmt"

func main() {
	a, b := 17, 5
	fmt.Println(a, "/", b, "=", a/b, "resto", a%b)
}

17 / 5 = 3 resto 2

Resumo

  • Os básicos: int, float64, string, bool; rune e byte são apelidos de inteiros.
  • Inteiro dividido por inteiro dá inteiro; % dá o resto.
  • Inteiros têm limite e podem estourar; floats são aproximados.
