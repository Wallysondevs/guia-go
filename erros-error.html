Erros (o tipo error)

Go não tem exceções com try/catch. Um erro é um valor comum, do tipo error, devolvido junto com o resultado. Quem chama confere com if err != nil e decide o que fazer. Parece repetitivo no começo, mas deixa claro, em cada linha, onde algo pode falhar.

Você vai aprender
  • Devolver erros com errors.New e fmt.Errorf, e nil quando deu certo.
  • Conferir com if err != nil e reagir: avisar, pular, encerrar.
  • Embrulhar um erro com %w, acrescentando contexto, e encerrar com os.Exit(1).
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Criando e devolvendo erros

package main

import (
	"errors"
	"fmt"
)

func sacar(saldo, valor float64) (float64, error) {
	if valor <= 0 {
		return saldo, errors.New("valor precisa ser positivo")
	}
	if valor > saldo {
		return saldo, fmt.Errorf("saldo insuficiente: tem %.2f, pediu %.2f", saldo, valor)
	}
	return saldo - valor, nil
}

func main() {
	saldo := 100.0
	for _, v := range []float64{30, -5, 500} {
		novo, err := sacar(saldo, v)
		if err != nil {
			fmt.Println("erro:", err)
			continue
		}
		saldo = novo
		fmt.Println("sacou", v, "- saldo:", saldo)
	}
}
$ go run main.go
sacou 30 - saldo: 70
erro: valor precisa ser positivo
erro: saldo insuficiente: tem 70.00, pediu 500.00
(float64, error)
o resultado e o erro.
errors.New("…")
cria um erro com uma mensagem fixa.
fmt.Errorf("… %.2f", …)
cria um erro com a mensagem formatada, como um Sprintf.
return …, nil
nil no lugar do erro quer dizer “deu certo”.

Mensagens de erro em Go costumam começar com letra minúscula e não terminar com ponto, porque muitas vezes são emendadas em outras.

2. Embrulhar com %w e encerrar

O %w do fmt.Errorf põe o erro original dentro de um novo, com mais contexto. A mensagem final conta a história inteira. Quando não dá para continuar, os.Exit(1) encerra o programa com código de erro, e o go run avisa com exit status 1:

package main

import (
	"fmt"
	"os"
	"strconv"
)

func lerIdade(texto string) (int, error) {
	n, err := strconv.Atoi(texto)
	if err != nil {
		return 0, fmt.Errorf("idade inválida %q: %w", texto, err)
	}
	return n, nil
}

func main() {
	idade, err := lerIdade("trinta")
	if err != nil {
		fmt.Println(err)
		os.Exit(1)
	}
	fmt.Println("idade:", idade)
}
$ go run main.go
idade inválida "trinta": strconv.Atoi: parsing "trinta": invalid syntax
exit status 1

A aula errors.Is e errors.As mostra como abrir o embrulho para descobrir o erro original.

Quando dá errado

Fingir que o erro não existe

Se a função devolve um erro, você precisa recebê-lo (ou descartá-lo de propósito com _):

package main

import (
	"fmt"
	"strconv"
)

func main() {
	n := strconv.Atoi("42")
	fmt.Println(n)
}
$ go run main.go
# command-line-arguments
./main.go:9:7: assignment mismatch: 1 variable but strconv.Atoi returns 2 values

Referência rápida

Você escreveO que faz

Missão: complete dividir para devolver o erro divisão por zero quando b for 0. A main já confere o erro; a saída deve ser erro: divisão por zero. Lembre de importar o pacote errors.

package main

import "fmt"

func dividir(a, b float64) (float64, error) {
	return a / b, nil
}

func main() {
	r, err := dividir(10, 0)
	if err != nil {
		fmt.Println("erro:", err)
		return
	}
	fmt.Println(r)
}

package main

import (
	"errors"
	"fmt"
)

func dividir(a, b float64) (float64, error) {
	if b == 0 {
		return 0, errors.New("divisão por zero")
	}
	return a / b, nil
}

func main() {
	r, err := dividir(10, 0)
	if err != nil {
		fmt.Println("erro:", err)
		return
	}
	fmt.Println(r)
}

erro: divisão por zero

Resumo

  • Erro é um valor do tipo error; nil quer dizer “sem erro”.
  • Crie com errors.New ou fmt.Errorf; embrulhe com %w.
  • Confira sempre com if err != nil.
