Arrays

Um array é uma fileira de caixas do mesmo tipo, com um tamanho fixo. Em Go o tamanho faz parte do tipo: [3]int e [4]int são tipos diferentes. Na prática você vai usar mais os slices, mas eles são construídos em cima dos arrays, então vale entender primeiro.

Você vai aprender
  • Declarar [N]tipo, ler e escrever com índice (começando em 0) e usar len.
  • Deixar o Go contar o tamanho com [...].
  • Ver que atribuir um array copia tudo, e que arrays podem ser comparados.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Criando e acessando

package main

import "fmt"

func main() {
	var notas [3]float64
	notas[0] = 7.5
	notas[2] = 9
	fmt.Println(notas, len(notas))

	dias := [7]string{"dom", "seg", "ter", "qua", "qui", "sex", "sáb"}
	fmt.Println(dias[1], dias[len(dias)-1])

	primos := [...]int{2, 3, 5, 7, 11}
	fmt.Printf("%v tem tipo %T\n", primos, primos)
}
$ go run main.go

A posição que ninguém preencheu ficou com o valor zero (0). A última posição é sempre len(x)-1.

2. Arrays são copiados

Atribuir um array a outra variável copia todos os valores: mudar b não muda a. Arrays do mesmo tipo podem ser comparados com ==. E dá para ter array de array:

package main

import "fmt"

func main() {
	a := [3]int{1, 2, 3}
	b := a // copia o array inteiro
	b[0] = 100
	fmt.Println("a:", a, "b:", b)
	fmt.Println("iguais?", a == [3]int{1, 2, 3})

	var grade [2][3]int
	grade[1][2] = 5
	fmt.Println(grade)
}
$ go run main.go
a: [1 2 3] b: [100 2 3]
iguais? true
[[0 0 0] [0 0 5]]

Quando dá errado

Índice fora do array (o compilador vê) 
package main

import "fmt"

func main() {
	dias := [3]string{"seg", "ter", "qua"}
	fmt.Println(dias[3])
}
$ go run main.go
# command-line-arguments
./main.go:7:19: invalid argument: index 3 out of bounds [0:3]
Índice fora do array (só com o programa rodando)

Se o índice está numa variável, o erro só aparece na execução, como um panic, que para o programa:

package main

import "fmt"

func main() {
	dias := [3]string{"seg", "ter", "qua"}
	i := 3
	fmt.Println(dias[i])
}
$ go run main.go
panic: runtime error: index out of range [3] with length 3

goroutine 1 [running]:
main.main()
	/home/ana/projetos/erro-array2/main.go:8 +0x9
exit status 2

O exit status 2 no fim é o go run avisando que o programa terminou com erro.

Tamanhos diferentes são tipos diferentes 
package main

import "fmt"

func main() {
	var a [3]int
	var b [4]int
	a = b
	fmt.Println(a)
}
$ go run main.go
# command-line-arguments
./main.go:8:6: cannot use b (variable of type [4]int) as [3]int value in assignment

Resumo

  • [N]tipo: tamanho fixo, que faz parte do tipo.
  • Índices de 0 a len-1; fora disso, erro de compilação ou panic.
  • Atribuir array copia tudo; no dia a dia, use slices.
