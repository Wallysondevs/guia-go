defer

O defer (adiar) agenda uma chamada para rodar quando a função terminar, aconteça o que acontecer. É o jeito Go de não esquecer de fechar um arquivo ou liberar um recurso: você escreve o “fechar” logo depois do “abrir”.

Você vai aprender
  • O defer roda no fim da função, mesmo com return no meio.
  • Vários defer rodam em ordem inversa (o último agendado roda primeiro).
  • Os argumentos são avaliados na hora do defer, não no fim.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. A ideia

package main

import "fmt"

func main() {
	fmt.Println("abrindo a loja")
	defer fmt.Println("fechando a loja")
	fmt.Println("atendendo clientes")
}
$ go run main.go
abrindo a loja
atendendo clientes
fechando a loja

O defer está na segunda linha, mas a frase dele saiu por último: ela esperou a main terminar.

2. Ordem inversa e argumentos na hora

Os defer formam uma pilha: o último a entrar é o primeiro a sair. E o valor de x foi “fotografado” quando o defer foi escrito (10), não no fim (20):

package main

import "fmt"

func main() {
	for i := 1; i <= 3; i++ {
		defer fmt.Println("defer", i)
	}
	x := 10
	defer fmt.Println("x no defer:", x)
	x = 20
	fmt.Println("x no fim:", x)
}
$ go run main.go
x no fim: 20
x no defer: 10
defer 3
defer 2
defer 1

3. O uso de verdade: fechar o que abriu

Abriu um arquivo? Escreva defer f.Close() logo em seguida. Mesmo que a função tenha vários return, o arquivo será fechado. Repare que, quando o os.Open falha, a função volta antes de chegar nos defer, e eles não rodam:

package main

import (
	"fmt"
	"os"
)

func lerTamanho(nome string) {
	f, err := os.Open(nome)
	if err != nil {
		fmt.Println("erro:", err)
		return
	}
	defer f.Close()
	defer fmt.Println("fechando", nome)

	info, _ := f.Stat()
	fmt.Println(nome, "tem", info.Size(), "bytes")
}

func main() {
	os.WriteFile("nota.txt", []byte("comprar pão\n"), 0644)
	lerTamanho("nota.txt")
	lerTamanho("sumiu.txt")
}
$ go run main.go
nota.txt tem 13 bytes
fechando nota.txt
erro: open sumiu.txt: no such file or directory

Quando dá errado

defer sem chamar a função

O defer precisa de uma chamada, com parênteses:

package main

import "fmt"

func main() {
	defer fmt.Println
	fmt.Println("oi")
}
$ go run main.go
# command-line-arguments
./main.go:6:8: expression in defer must be function call

4. Quando um defer roda?

Missão: use defer para que a mensagem tchau! seja a última linha, mesmo escrita logo no começo da main.

package main

import "fmt"

func main() {
	fmt.Println("tchau!")
	fmt.Println("olá")
	fmt.Println("tudo bem?")
}

package main

import "fmt"

func main() {
	defer fmt.Println("tchau!")
	fmt.Println("olá")
	fmt.Println("tudo bem?")
}

olá
tudo bem?
tchau!

Resumo

  • defer adia a chamada para o fim da função.
  • Vários defer rodam em ordem inversa.
  • Os argumentos são avaliados na hora; use defer f.Close() logo depois de abrir.
