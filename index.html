Tutorial Go

Aprenda a linguagem Go do zero, como numa escola: cada aula explica um assunto só, mostra o código inteiro e a resposta de verdade do terminal, colhida rodando o programa com Go 1.27.3. Do Olá, mundo! até goroutines, channels e um servidor web.

Comece aqui ❯

A primeira aula é O que é Go. Depois vêm a instalação, o primeiro programa e, uma a uma, as aulas da linguagem.

O que é este guia

Go (ou Golang) é uma linguagem compilada, simples e rápida, criada no Google. Ela é muito usada em servidores, ferramentas de linha de comando e na nuvem: Docker e Kubernetes são escritos em Go.

O guia é para quem está começando a programar ou vem de outra linguagem. Ele começa do zero (o que é um programa compilado? como se roda?) e vai até concorrência, testes, JSON e rede. Cada aula traz a explicação, a anatomia do código, a saída real, a parte “Quando dá errado” com a mensagem do compilador, exercícios e missões.

O texto está em português do Brasil. O código fica em Go, como a linguagem pede (func, for, if), mas os nomes de variáveis e as mensagens dos exemplos estão em português. As mensagens de erro do Go não são traduzidas: aparecem exatamente como o compilador escreveu, com a explicação em português em seguida.

Como estudar

Programação se aprende programando. Para cada aula, siga estes quatro passos:

  1. Leia com calma. Leia a ideia, a anatomia e a saída. Não pule a parte “Quando dá errado”.
  2. Rode os exemplos. Copie o código, salve num arquivo main.go e rode com go run main.go no seu computador.
  3. Faça as missões e os exercícios. Nas caixas Missão, você roda o código no seu terminal e cola a saída: a página confere se você acertou. Tente de verdade antes de abrir a solução.
  4. Mude o código. Troque um valor, apague uma linha, provoque um erro. Ler a mensagem do compilador é metade do aprendizado.
A regra de ouro

Ler não basta: digite o código. Copiar e colar ensina pouco; digitar faz você reparar em cada chave, cada aspa e cada letra maiúscula. Comece aqui, pela aula O que é Go.

Sobre as saídas

Todas as saídas foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64). Nos exemplos, a usuária fictícia é a ana, o computador se chama notebook e os projetos ficam em ~/projetos. O código Go funciona igual no Windows e no macOS.
