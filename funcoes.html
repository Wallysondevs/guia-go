Funções

Uma função é um pedaço de código com nome, que recebe valores (parâmetros), faz um trabalho e pode devolver um resultado. Em vez de repetir o mesmo código, você chama a função. Em Go, os tipos dos parâmetros e do retorno são escritos depois do nome.

Você vai aprender
  • Declarar func nome(param tipo) tipoRetorno e usar return.
  • Funções variádicas (...int), funções guardadas em variáveis e closures.
  • Por que mudar um parâmetro int não muda a variável de fora, mas mudar um slice muda.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Declarando e chamando

package main

import "fmt"

func saudar(nome string) {
	fmt.Println("Olá,", nome)
}

func dobro(x int) int {
	return x * 2
}

func area(largura, altura float64) float64 {
	return largura * altura
}

func main() {
	saudar("Ana")
	fmt.Println(dobro(21))
	fmt.Println(area(3, 2.5))
}
$ go run main.go
Olá, Ana
42
7.5
func

dobro
o nome.
(x int)
o parâmetro x, do tipo int.
int
o tipo do valor devolvido.
return x * 2
devolve o resultado e sai da função.

Parâmetros seguidos do mesmo tipo podem dividir o tipo: (largura, altura float64). A função saudar não devolve nada, então não tem tipo de retorno.

2. Variádicas, funções como valor e closures

Com ...int a função aceita quantos inteiros você quiser (dentro dela, numeros é um slice). Para passar um slice inteiro, use lista.... Funções também são valores: dá para guardar numa variável, passar para outra função e até devolver uma função que “lembra” de uma variável (uma closure):

package main

import "fmt"

func somar(numeros ...int) int {
	total := 0
	for _, n := range numeros {
		total += n
	}
	return total
}

func aplicar(x int, f func(int) int) int {
	return f(x)
}

func contador() func() int {
	c := 0
	return func() int {
		c++
		return c
	}
}

func main() {
	fmt.Println(somar(), somar(1, 2), somar(1, 2, 3, 4))
	lista := []int{10, 20, 30}
	fmt.Println(somar(lista...))

	quadrado := func(n int) int { return n * n }
	fmt.Println(aplicar(5, quadrado))

	proximo := contador()
	fmt.Println(proximo(), proximo(), proximo())
}
$ go run main.go
0 3 10
60
25
1 2 3

3. Go passa cópias

Os argumentos chegam como cópias. Zerar n dentro de zerar não muda o x de fora. Já o slice é uma janela para um array: a cópia da janela aponta para o mesmo array, então a mudança aparece fora. Para mudar um int de fora, use um ponteiro (aula Ponteiros).

package main

import "fmt"

func zerar(n int) {
	n = 0
}

func zerarPrimeiro(s []int) {
	s[0] = 0
}

func main() {
	x := 10
	zerar(x)
	fmt.Println("x:", x)

	lista := []int{1, 2, 3}
	zerarPrimeiro(lista)
	fmt.Println("lista:", lista)
}
$ go run main.go
x: 10
lista: [0 2 3]

Quando dá errado

Esqueceu o return 
package main

import "fmt"

func dobro(x int) int {
	x * 2
}

func main() {
	fmt.Println(dobro(2))
}
$ go run main.go
# command-line-arguments
./main.go:6:2: x * 2 (value of type int) is not used
./main.go:7:1: missing return

Duas mensagens: a conta x * 2 foi calculada e jogada fora, e a função, que promete devolver um int, termina sem return.

Argumentos a menos ou do tipo errado 
package main

import "fmt"

func area(largura, altura float64) float64 {
	return largura * altura
}

func main() {
	fmt.Println(area(3))
	fmt.Println(area(3, "2"))
}

Missão: escreva a função maior(a, b int) int, que devolve o maior dos dois. A saída deve ser 9.

package main

import "fmt"

// escreva a função maior aqui

func main() {
	fmt.Println(9)
}

package main

import "fmt"

func maior(a, b int) int {
	if a > b {
		return a
	}
	return b
}

func main() {
	fmt.Println(maior(4, 9))
}

9

Missão: escreva a função variádica media(nums ...float64) float64. Com 6, 7 e 8, a saída deve ser média: 7.

package main

import "fmt"

func main() {
	fmt.Println("média:")
}

package main

import "fmt"

func media(nums ...float64) float64 {
	soma := 0.0
	for _, n := range nums {
		soma += n
	}
	return soma / float64(len(nums))
}

func main() {
	fmt.Println("média:", media(6, 7, 8))
}

média: 7

Resumo

  • func nome(param tipo) retorno { … }; return devolve.
  • Variádicas com ...; funções são valores e podem formar closures.
  • Argumentos são cópias; slices e maps compartilham os dados.
