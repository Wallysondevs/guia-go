Slices

O slice é a lista do dia a dia em Go: tem tamanho variável e cresce com append. Por baixo, ele é uma janela sobre um array. Entender essa janela explica por que mudar um pedaço pode mudar o original.

Você vai aprender
  • Criar slices, crescer com append e fatiar com [a:b].
  • len (quantos itens) e cap (quanto cabe antes de realocar), e o make.
  • Fatias compartilham memória; copy faz uma cópia de verdade. E o pacote slices.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. append e fatias

package main

import "fmt"

func main() {
	frutas := []string{"maçã", "banana"}
	frutas = append(frutas, "uva")
	frutas = append(frutas, "kiwi", "pera")
	fmt.Println(frutas, len(frutas))

	numeros := []int{10, 20, 30, 40, 50}
	fmt.Println(numeros[1:3])
	fmt.Println(numeros[:2], numeros[3:])

	var vazio []int
	fmt.Println(vazio, len(vazio), vazio == nil)
}
$ go run main.go
[maçã banana uva kiwi pera] 5
[20 30]
[10 20] [40 50]
[] 0 true

guarde o resultado: o append não muda a variável sozinho.

A fatia numeros[1:3] pega da posição 1 até antes da 3. Sem o começo, começa do 0; sem o fim, vai até o final. Um slice declarado sem valor é nil, com tamanho 0, e já pode receber append.

2. len, cap e make

make([]int, 0, 2) cria um slice vazio com espaço para 2. Quando o espaço acaba, o append arruma um array maior e copia tudo; repare como o cap pula:

package main

import "fmt"

func main() {
	s := make([]int, 0, 2)
	for i := 1; i <= 5; i++ {
		s = append(s, i)
		fmt.Printf("len=%d cap=%d %v\n", len(s), cap(s), s)
	}
}
$ go run main.go
len=1 cap=2 [1]
len=2 cap=2 [1 2]
len=3 cap=4 [1 2 3]
len=4 cap=4 [1 2 3 4]
len=5 cap=8 [1 2 3 4 5]

3. Fatias compartilham; copy copia

Uma fatia é uma janela sobre o mesmo array: escrever nela muda o original. Para ter uma cópia independente, use copy. O pacote slices traz funções prontas:

package main

import (
	"fmt"
	"slices"
)

func main() {
	original := []int{1, 2, 3, 4}
	pedaco := original[0:2]
	pedaco[0] = 99
	fmt.Println("original:", original, "pedaço:", pedaco)

	copia := make([]int, len(original))
	copy(copia, original)
	copia[1] = 0
	fmt.Println("original:", original, "cópia:", copia)

	nomes := []string{"Rui", "Ana", "Bia"}
	slices.Sort(nomes)
	fmt.Println(nomes, slices.Contains(nomes, "Ana"), slices.Index(nomes, "Rui"))
}
$ go run main.go
original: [99 2 3 4] pedaço: [99 2]
original: [99 2 3 4] cópia: [99 0 3 4]
[Ana Bia Rui] true 2

Resumo

  • Slice é lista que cresce: s = append(s, x).
  • s[a:b] fatia; len e cap medem; make cria.
  • Fatias compartilham o array; copy faz cópia independente.
