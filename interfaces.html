Interfaces

Uma interface é um contrato: uma lista de métodos. Qualquer tipo que tenha esses métodos cumpre o contrato, sem precisar dizer isso em lugar nenhum. É assim que uma função Go aceita “qualquer coisa que tenha Area()”, seja retângulo, círculo ou algo que ainda nem existe.

Você vai aprender
  • Declarar type Forma interface { Area() float64 } e usar tipos diferentes no mesmo lugar.
  • A implementação implícita e a interface fmt.Stringer.
  • O tipo any, a type assertion v.(T) e o type switch.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Um contrato, vários tipos

package main

import (
	"fmt"
	"math"
)

type Forma interface {
	Area() float64
}

type Retangulo struct{ L, A float64 }
type Circulo struct{ R float64 }

func (r Retangulo) Area() float64 { return r.L * r.A }
func (c Circulo) Area() float64   { return math.Pi * c.R * c.R }

func main() {
	formas := []Forma{Retangulo{3, 4}, Circulo{1}}
	total := 0.0
	for _, f := range formas {
		fmt.Printf("%T: %.2f\n", f, f.Area())
		total += f.Area()
	}
	fmt.Printf("total: %.2f\n", total)
}
$ go run main.go
main.Retangulo: 12.00
main.Circulo: 3.14
total: 15.14

Retangulo e Circulo nunca dizem “eu implemento Forma”. Basta terem o método Area() float64. Por isso os dois cabem no mesmo []Forma, e o laço chama o Area certo de cada um.

2. Stringer, any e descobrir o tipo

A interface fmt.Stringer tem só String() string: quem a cumpre controla como é escrito pelo fmt. O any (interface vazia) aceita qualquer valor; para usar o valor, você pergunta o tipo com v.(T) ou com um switch v.(type):

package main

import "fmt"

type Pessoa struct {
	Nome  string
	Idade int
}

func (p Pessoa) String() string {
	return fmt.Sprintf("%s (%d anos)", p.Nome, p.Idade)
}

func descrever(v any) string {
	switch x := v.(type) {
	case int:
		return fmt.Sprint("inteiro ", x)
	case string:
		return "texto de " + fmt.Sprint(len(x)) + " bytes"
	case fmt.Stringer:
		return "Stringer: " + x.String()
	default:
		return fmt.Sprintf("outro tipo: %T", x)
	}
}

func main() {
	ana := Pessoa{"Ana", 30}
	fmt.Println(ana)
	for _, v := range []any{42, "olá", ana, 3.5} {
		fmt.Println(descrever(v))
	}

	var algo any = "Go"
	s, ok := algo.(string)
	fmt.Println(s, ok)
	n, ok := algo.(int)
	fmt.Println(n, ok)
}
$ go run main.go
Ana (30 anos)
inteiro 42
texto de 4 bytes
Stringer: Ana (30 anos)
outro tipo: float64
Go true
0 false

A forma com dois valores, s, ok := algo.(string), não dá panic: quando o tipo não confere, ok vem false e o valor vem zero.

Quando dá errado

Faltou um método do contrato 
package main

import "fmt"

type Forma interface {
	Area() float64
	Perimetro() float64
}

type Quadrado struct{ L float64 }

func (q Quadrado) Area() float64 { return q.L * q.L }

func main() {
	var f Forma = Quadrado{2}
	fmt.Println(f.Area())
}
$ go run main.go
# command-line-arguments
./main.go:15:16: cannot use Quadrado{…} (value of struct type Quadrado) as Forma value in variable declaration: Quadrado does not implement Forma (missing method Perimetro)
Type assertion de um valor só, com o tipo errado 
package main

import "fmt"

func main() {
	var algo any = "Go"
	n := algo.(int)
	fmt.Println(n)
}
$ go run main.go
panic: interface conversion: interface {} is string, not int

goroutine 1 [running]:
main.main()
	/home/ana/projetos/erro-assert/main.go:7 +0x28
exit status 2

Use a forma n, ok := algo.(int) quando não tiver certeza.

Missão: crie o tipo Cachorro com o método Som() string que devolve au au, para ele cumprir a interface Animal. A saída deve ser Cachorro faz au au.

package main

import "fmt"

type Animal interface {
	Som() string
}

// crie o tipo Cachorro e o método aqui

func main() {
	var a Animal
	fmt.Println(a)
}

package main

import "fmt"

type Animal interface {
	Som() string
}

type Cachorro struct{}

func (c Cachorro) Som() string { return "au au" }

func main() {
	var a Animal = Cachorro{}
	fmt.Println("Cachorro faz", a.Som())
}

Cachorro faz au au

Missão: dê ao tipo Produto um método String() string para o fmt.Println(p) escrever café: R$ 4.50.

package main

import "fmt"

type Produto struct {
	Nome  string
	Preco float64
}

func main() {
	p := Produto{"café", 4.5}
	fmt.Println(p)
}

package main

import "fmt"

type Produto struct {
	Nome  string
	Preco float64
}

func (p Produto) String() string {
	return fmt.Sprintf("%s: R$ %.2f", p.Nome, p.Preco)
}

func main() {
	p := Produto{"café", 4.5}
	fmt.Println(p)
}

café: R$ 4.50

Resumo

  • Interface é uma lista de métodos; quem tem os métodos cumpre o contrato.
  • fmt.Stringer controla como um tipo é escrito.
  • any aceita tudo; descubra o tipo com v.(T) ou switch v.(type).
