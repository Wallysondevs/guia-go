Pacotes e Módulos

Quando o programa cresce, você divide o código em pacotes: uma pasta para cada assunto. O módulo (o go.mod) dá o nome-base dos caminhos de import. E a regra de visibilidade do Go é a mais simples que existe: nome com maiúscula é visível fora do pacote; com minúscula, não.

Você vai aprender
  • Criar um pacote numa subpasta e importá-lo com modulo/pasta.
  • Exportar com maiúscula (ComDesconto) e esconder com minúscula (arredondar).
  • Ver a estrutura com go list e a documentação com go doc.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Um módulo com dois pacotes

O módulo loja tem o pacote main na raiz e o pacote precos na pasta precos/:

$ find . -type f | sort
./go.mod
./main.go
./precos/precos.go
module loja

go 1.27.3
package main

import (
	"fmt"

	"loja/precos"
)

func main() {
	total := precos.ComDesconto(100, 15)
	fmt.Printf("total: R$ %.2f\n", total)
	fmt.Println("moeda:", precos.Moeda)
}
// Package precos calcula preços da loja.
package precos

// Moeda é exportada: começa com maiúscula.
const Moeda = "BRL"

// ComDesconto aplica um desconto em porcentagem.
func ComDesconto(valor, porcento float64) float64 {
	return arredondar(valor * (1 - porcento/100))
}

// arredondar não é exportada: só o pacote precos enxerga.
func arredondar(v float64) float64 {
	return float64(int(v*100+0.5)) / 100
}
$ go run .
total: R$ 85.00
moeda: BRL
"loja/precos"
caminho de import: nome do módulo + pasta.
precos.ComDesconto
uso: nome do pacote + ponto + nome exportado.
package precos
primeira linha de todos os arquivos da pasta.

2. go list e go doc

Os comentários logo acima das declarações exportadas viram documentação, que o go doc mostra no terminal:

$ go list ./...
loja
loja/precos
$ go doc ./precos
package precos // import "loja/precos"

Package precos calcula preços da loja.

const Moeda = "BRL"
func ComDesconto(valor, porcento float64) float64
$ go doc ./precos ComDesconto
package precos // import "loja/precos"

func ComDesconto(valor, porcento float64) float64
    ComDesconto aplica um desconto em porcentagem.

Quando dá errado

Usar um nome não exportado 
package main

import (
	"fmt"

	"loja/precos"
)

func main() {
	fmt.Println(precos.arredondar(9.999))
}
$ go run .
# loja
./main.go:10:21: name arredondar not exported by package precos
Importar um pacote que não existe 
package main

import (
	"fmt"

	"loja/estoque"
)

func main() {
	fmt.Println(estoque.Total())
}
$ go run .
main.go:6:2: package loja/estoque is not in std (/usr/local/go/src/loja/estoque)

Referência rápida

Você escreveO que faz
uma pasta = um pacoteTodos os arquivos da pasta têm o mesmo package.
import "modulo/pasta"Importa um pacote do seu módulo.
Maiuscula / minusculaExportado / visível só no pacote.
go list ./...Lista os pacotes do módulo.
go doc ./pasta NomeMostra a documentação.

Resumo

  • Uma pasta é um pacote; o import é modulo/pasta.
  • Maiúscula exporta; minúscula esconde.
  • go list mostra os pacotes; go doc, a documentação.
