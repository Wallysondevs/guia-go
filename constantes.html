Constantes (const e iota)

Uma constante é um valor que nunca muda enquanto o programa roda: o número pi, os dias da semana, um limite. Em Go ela é declarada com const e conferida pelo compilador. Nesta aula você também conhece o iota, um contador automático para listas de constantes.

Você vai aprender
  • Declarar constantes com const, dentro e fora de funções.
  • Agrupar constantes num bloco const ( … ).
  • Numerar com iota e pular valores com _.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. const

package main

import "fmt"

const pi = 3.14159
const saudacao = "Bem-vinda"

func main() {
	const diasNaSemana = 7
	raio := 2.0
	fmt.Println(saudacao, "à aula de constantes!")
	fmt.Println("área do círculo:", pi*raio*raio)
	fmt.Println("dias:", diasNaSemana, "horas:", diasNaSemana*24)
}
$ go run main.go
Bem-vinda à aula de constantes!
área do círculo: 12.56636
dias: 7 horas: 168

Constantes podem ficar fora de funções (valem no arquivo todo) ou dentro (valem só ali). Elas aceitam contas, como diasNaSemana*24, que o compilador faz antes de o programa rodar.

2. iota: o contador automático

Dentro de um bloco const ( … ), o iota vale 0 na primeira linha, 1 na segunda, 2 na terceira… E as linhas sem valor repetem a expressão de cima. Com isso, numerar os dias da semana ou calcular potências fica numa linha só:

package main

import "fmt"

const (
	Domingo = iota
	Segunda
	Terca
	Quarta
)

const (
	_  = iota
	KB = 1 << (10 * iota)
	MB
	GB
)

func main() {
	fmt.Println(Domingo, Segunda, Terca, Quarta)
	fmt.Println("KB:", KB, "MB:", MB, "GB:", GB)
}
$ go run main.go
0 1 2 3
KB: 1024 MB: 1048576 GB: 1073741824
_ = iota
joga fora o 0 (o _ é o “nome em branco”).
KB = 1 << (10 * iota)
1 deslocado 10 bits para a esquerda: 1024.
MB
repete a expressão com iota = 2: 1024 × 1024.

Quando dá errado

Tentar mudar uma constante 
package main

import "fmt"

func main() {
	const limite = 10
	limite = 20
	fmt.Println(limite)
}
$ go run main.go
# command-line-arguments
./main.go:7:2: cannot assign to limite (neither addressable nor a map index expression)
Constante com valor que só existe com o programa rodando

O valor de uma constante precisa ser conhecido na compilação. O tamanho de uma variável não é:

package main

import "fmt"

func main() {
	nome := "Ana"
	const tamanho = len(nome)
	fmt.Println(tamanho)
}
$ go run main.go
# command-line-arguments
./main.go:7:18: len(nome) (value of type int) is not constant

Aqui o certo é tamanho := len(nome), uma variável.

Referência rápida

Você escreveO que faz

_ = iotaPula um valor.

Missão: complete o bloco com iota para que Ouro valha 0, Prata 1 e Bronze 2. O programa deve escrever 0 1 2.

package main

import "fmt"

const (
	Ouro = 0
	Prata = 0
	Bronze = 0
)

func main() {
	fmt.Println(Ouro, Prata, Bronze)
}

package main

import "fmt"

const (
	Ouro = iota
	Prata
	Bronze
)

func main() {
	fmt.Println(Ouro, Prata, Bronze)
}

0 1 2

Resumo

  • const cria valores que não mudam, conferidos na compilação.
  • Blocos const ( … ) agrupam constantes.
  • iota conta 0, 1, 2… e as linhas sem valor repetem a expressão.
