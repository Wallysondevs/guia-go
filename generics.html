Generics básicos

Sem generics, uma função Maior precisaria de uma versão para int, outra para float64, outra para string… Com parâmetros de tipo você escreve uma vez só, e o compilador confere, em cada chamada, se o tipo serve.

Você vai aprender
  • Escrever funções com [T restrição] e chamá-las com ou sem o tipo explícito.
  • As restrições any e cmp.Ordered, e criar a sua com ~int | ~float64.
  • Um tipo genérico, Pilha[T], com métodos.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Funções genéricas

package main

import (
	"cmp"
	"fmt"
)

func Maior[T cmp.Ordered](a, b T) T {
	if a > b {
		return a
	}
	return b
}

func Mapear[T, R any](lista []T, f func(T) R) []R {
	saida := make([]R, 0, len(lista))
	for _, v := range lista {
		saida = append(saida, f(v))
	}
	return saida
}

func main() {
	fmt.Println(Maior(3, 7))
	fmt.Println(Maior("abacaxi", "banana"))
	fmt.Println(Maior[float64](2.5, 1))

	nomes := []string{"ana", "rui"}
	tamanhos := Mapear(nomes, func(s string) int { return len(s) })
	fmt.Println(tamanhos)
}
$ go run main.go
7
banana
2.5
[3 3]
[T cmp.Ordered]
o parâmetro de tipo T, que precisa ser “ordenável” (aceitar < e >).
(a, b T) T
recebe dois T e devolve um T.
Maior[float64](2.5, 1)
o tipo pode ser dito na chamada; quase sempre o Go deduz sozinho.

2. Tipos genéricos e restrições próprias

Uma struct também pode ter parâmetro de tipo: Pilha[string] só aceita strings. Para devolver “nada” de um T qualquer, use var zero T. E a restrição Numero aceita int, float64 e tipos baseados neles (o ~):

package main

import "fmt"

type Pilha[T any] struct {
	itens []T
}

func (p *Pilha[T]) Empilhar(v T) {
	p.itens = append(p.itens, v)
}

func (p *Pilha[T]) Desempilhar() (T, bool) {
	var zero T
	if len(p.itens) == 0 {
		return zero, false
	}
	ultimo := p.itens[len(p.itens)-1]
	p.itens = p.itens[:len(p.itens)-1]
	return ultimo, true
}

type Numero interface {
	~int | ~float64
}

func Somar[T Numero](nums ...T) T {
	var total T
	for _, n := range nums {
		total += n
	}
	return total
}

func main() {
	var p Pilha[string]
	p.Empilhar("a")
	p.Empilhar("b")
	v, ok := p.Desempilhar()
	fmt.Println(v, ok)
	v, ok = p.Desempilhar()
	fmt.Println(v, ok)
	v, ok = p.Desempilhar()
	fmt.Printf("%q %v\n", v, ok)

	fmt.Println(Somar(1, 2, 3), Somar(0.5, 0.25))
}
$ go run main.go
b true
a true
"" false
6 0.75

Quando dá errado

Tipo que não cumpre a restrição

bool não tem ordem (não dá para dizer se true > false):

package main

import (
	"cmp"
	"fmt"
)

func Maior[T cmp.Ordered](a, b T) T {
	if a > b {
		return a
	}
	return b
}

func main() {
	fmt.Println(Maior(true, false))
}
$ go run main.go

Missão: escreva a função genérica Contem[T comparable](lista []T, alvo T) bool. A saída deve ser true false.

package main

import "fmt"

func main() {
	fmt.Println([]int{1, 2, 3}, []string{"a", "b"})
}

package main

import "fmt"

func Contem[T comparable](lista []T, alvo T) bool {
	for _, v := range lista {
		if v == alvo {
			return true
		}
	}
	return false
}

func main() {
	fmt.Println(Contem([]int{1, 2, 3}, 2), Contem([]string{"a", "b"}, "z"))
}

true false

Resumo

  • Parâmetros de tipo: func F[T restrição](…).
  • any aceita tudo; cmp.Ordered, o que tem ordem; comparable, o que aceita ==.
  • Tipos também podem ser genéricos: Pilha[T].
