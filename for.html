for

Go tem um laço só, o for, mas ele faz tudo: contar de 1 a 10, repetir enquanto uma condição valer (o while de outras linguagens), rodar para sempre até um break e percorrer listas com range.

Você vai aprender
  • O for clássico: início; condição; passo.
  • O for como while, o infinito e o range (inclusive range 3).
  • break e continue.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Contador, condição e range de um número

package main

import "fmt"

func main() {
	for i := 1; i <= 3; i++ {
		fmt.Println("volta", i)
	}

	contagem := 3
	for contagem > 0 {
		fmt.Println("faltam", contagem)
		contagem--
	}

	for i := range 3 {
		fmt.Print(i, " ")
	}
	fmt.Println()
}
$ go run main.go
volta 1
volta 2
volta 3
faltam 3
faltam 2
faltam 1
0 1 2
i := 1
início: roda uma vez.
i <= 3
condição: conferida antes de cada volta.
i++
passo: roda no fim de cada volta.

Com só a condição, o for vira um “enquanto”. E for i := range 3 conta de 0 a 2.

2. range em listas e textos

O range entrega a posição e o valor de cada item. Se você não precisa de um deles, troque por _. Num texto, ele anda de caractere em caractere, e a posição é em bytes: o é ocupa dois bytes.

package main

import "fmt"

func main() {
	frutas := []string{"maçã", "banana", "uva"}
	for i, f := range frutas {
		fmt.Println(i, f)
	}
	for _, f := range frutas {
		fmt.Print(f, ";")
	}
	fmt.Println()

	for i, letra := range "pé" {
		fmt.Println(i, string(letra))
	}
}
$ go run main.go
0 maçã
1 banana
2 uva
maçã;banana;uva;
0 p
1 é

3. break, continue e o laço infinito

continue pula para a próxima volta; break sai do laço. Um for sem nada é infinito e só termina com break (ou return):

package main

import "fmt"

func main() {
	for i := 1; i <= 10; i++ {
		if i%2 == 0 {
			continue // pula os pares
		}
		if i > 7 {
			break // para tudo
		}
		fmt.Print(i, " ")
	}
	fmt.Println()

	n := 0
	for {
		n++
		if n*n > 50 {
			break
		}
	}
	fmt.Println("primeiro n com n² > 50:", n)
}
$ go run main.go
1 3 5 7 
primeiro n com n² > 50: 8

Quando dá errado

Não existe while 
package main

import "fmt"

func main() {
	i := 0
	while i < 3 {
		i++
	}
	fmt.Println(i)
}
$ go run main.go
# command-line-arguments
./main.go:7:8: syntax error: unexpected name i at end of statement
./main.go:10:2: syntax error: non-declaration statement outside function body

Em Go é for i < 3 { … }.

Parênteses em volta do for 
package main

import "fmt"

func main() {
	for (i := 0; i < 3; i++) {
		fmt.Println(i)
	}
}
$ go run main.go
# command-line-arguments
./main.go:6:9: syntax error: unexpected :=, expected )

Missão: percorra a lista com range e some os valores. A saída deve ser soma: 100.

package main

import "fmt"

func main() {
	valores := []int{10, 20, 30, 40}
	soma := 0
	fmt.Println("soma:", soma)
}

package main

import "fmt"

func main() {
	valores := []int{10, 20, 30, 40}
	soma := 0
	for _, v := range valores {
		soma += v
	}
	fmt.Println("soma:", soma)
}

soma: 100

Resumo

  • Go tem só o for: clássico, como while, infinito e com range.
  • range dá posição e valor; num texto, anda por caracteres.
  • break sai; continue pula a volta.
