O que é Go

Go (ou Golang) é uma linguagem de programação criada no Google e lançada em 2009. Ela é compilada: o seu código vira um programa executável de verdade, que roda sem precisar do Go instalado. Nesta aula você entende o que isso quer dizer e conhece a ferramenta go, que você vai usar em todas as aulas.

Você vai aprender
  • O que é uma linguagem compilada e por que o Go é rápido de compilar.
  • Onde o Go é usado: servidores, ferramentas de linha de comando, nuvem (Docker e Kubernetes são escritos em Go).
  • Como este guia funciona: você copia o código, roda no seu computador e cola a saída para conferir.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

A ideia: uma receita que vira um prato pronto

Pense no código-fonte como uma receita escrita em português. O computador não entende a receita: ele só entende o prato pronto. O compilador é o cozinheiro que lê a receita inteira, avisa se faltou algum ingrediente (os erros de compilação) e entrega o prato: um arquivo executável.

Em linguagens interpretadas, como Python e JavaScript, o cozinheiro vai lendo e cozinhando linha por linha, na hora de servir. Em Go, tudo é conferido antes. Por isso muitos erros que no Python só aparecem com o programa rodando, em Go aparecem já na compilação.

1. Um programa Go de verdade

Este é o menor programa Go útil. Não se preocupe com cada palavra agora: a aula Olá, Mundo explica linha por linha.

package main

import "fmt"

func main() {
	fmt.Println("Olá, mundo!")
}
$ go run main.go
Olá, mundo!

O comando go run main.go compilou o arquivo e rodou o resultado na hora. A única coisa que o programa faz é escrever Olá, mundo!.

2. A ferramenta go

Tudo em Go passa por um único programa, o go. Ele compila, roda, testa, formata e baixa dependências. Os subcomandos que você mais vai usar neste guia:

ComandoPara que serveAula
go versionMostra a versão instalada.Instalação
go runCompila e roda na hora, sem deixar arquivo.go run e go build
go buildCompila e deixa o executável na pasta.go run e go build
go mod initCria um módulo (o “projeto”).Módulos
go testRoda os testes automáticos.Testes
gofmt / go vetFormata o código e procura erros comuns.go vet e gofmt

Rodar go sozinho mostra a lista de subcomandos. Este é o começo da resposta:

$ go help | head -n 12
Go is a tool for managing Go source code.

Usage:

	go <command> [arguments]

The commands are:

	bug         start a bug report
	build       compile packages and dependencies
	clean       remove object files and cached files
	doc         show documentation for package or symbol

3. Por que aprender Go

  • Simples. A linguagem tem poucas palavras-chave (25) e um jeito só de formatar o código (o gofmt).
  • Rápida. Compila em segundos e gera um executável único, fácil de copiar para um servidor.
  • Feita para servidores. Goroutines e channels (Nível 3) deixam fazer várias coisas ao mesmo tempo sem sofrimento.
  • Muito usada na nuvem. Docker, Kubernetes, Terraform e o próprio Hugo são escritos em Go.

4. Como este guia funciona

Cada aula traz o código, o comando e a saída real. No fim de cada aula há exercícios e caixas de Missão: você copia o código, salva num arquivo (quase sempre main.go), roda com go run main.go no terminal do seu computador e cola o que apareceu. A página confere a saída e o código e diz se a missão foi cumprida.

Windows, macOS ou Linux?

Tanto faz. As saídas deste guia foram colhidas num Linux, mas o código Go é o mesmo nos três sistemas. Muda só o jeito de abrir o terminal e, às vezes, o nome do executável (no Windows ele termina em .exe).
