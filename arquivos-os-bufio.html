Arquivos (os e bufio)

Quase todo programa de verdade lê ou grava arquivos. Em Go, os pacotes os e bufio cobrem o dia a dia: gravar e ler um arquivo inteiro numa linha, acrescentar no fim, ler linha a linha e até ler o que o usuário digita.

Você vai aprender
  • Gravar com os.WriteFile, ler com os.ReadFile e acrescentar com os.OpenFile.
  • Ler linha a linha com bufio.Scanner e listar uma pasta com os.ReadDir.
  • Ler a entrada padrão (os.Stdin) e escrever com bufio.Writer.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Gravar, acrescentar e ler

package main

import (
	"fmt"
	"os"
)

func main() {
	err := os.WriteFile("compras.txt", []byte("arroz\nfeijão\n"), 0644)
	if err != nil {
		fmt.Println("erro ao gravar:", err)
		return
	}

	f, err := os.OpenFile("compras.txt", os.O_APPEND|os.O_WRONLY, 0644)
	if err != nil {
		fmt.Println("erro ao abrir:", err)
		return
	}
	fmt.Fprintln(f, "café")
	f.Close()

	dados, err := os.ReadFile("compras.txt")
	if err != nil {
		fmt.Println("erro ao ler:", err)
		return
	}
	fmt.Print(string(dados))
	fmt.Println(len(dados), "bytes")
}
$ go run main.go
arroz
feijão
café
20 bytes
os.WriteFile(nome, dados, 0644)

As três palavras e as três quebras de linha somam 18 caracteres, mas o arquivo tem 20 bytes: o ã de feijão e o é de café ocupam dois bytes cada em UTF-8.

2. Linha a linha e listando a pasta

Para arquivos grandes, ler tudo de uma vez gasta memória. O bufio.Scanner entrega uma linha por vez, sem o \n:

package main

import (
	"bufio"
	"fmt"
	"os"
	"strings"
)

func main() {
	f, err := os.Open("compras.txt")
	if err != nil {
		fmt.Println(err)
		return
	}
	defer f.Close()

	sc := bufio.NewScanner(f)
	n := 0
	for sc.Scan() {
		n++
		fmt.Printf("%d: %s\n", n, strings.ToUpper(sc.Text()))
	}
	if err := sc.Err(); err != nil {
		fmt.Println("erro lendo:", err)
	}

	entradas, _ := os.ReadDir(".")
	for _, e := range entradas {
		fmt.Println("na pasta:", e.Name())
	}
}
$ go run ler.go
1: ARROZ
2: FEIJÃO
3: CAFÉ
na pasta: compras.txt
na pasta: ler.go
na pasta: main.go

3. Lendo o que vem do teclado (ou de outro programa)

os.Stdin é a entrada padrão: o teclado, ou a saída de outro comando ligada com |. Aqui o printf manda dois nomes para o programa:

package main

import (
	"bufio"
	"fmt"
	"os"
)

func main() {
	sc := bufio.NewScanner(os.Stdin)
	w := bufio.NewWriter(os.Stdout)
	defer w.Flush()
	for sc.Scan() {
		fmt.Fprintf(w, "Olá, %s!\n", sc.Text())
	}
}
$ printf 'Ana\nRui\n' | go run main.go
Olá, Ana!
Olá, Rui!

O bufio.Writer junta a saída num buffer e escreve de uma vez; o defer w.Flush() garante que nada fica para trás.

Quando dá errado

Arquivo, pasta ou tipo errado

Os erros do pacote os dizem a operação, o caminho e o motivo. Ler um arquivo que não existe, gravar numa pasta que não existe e tentar ler uma pasta como se fosse arquivo:

package main

import (
	"fmt"
	"os"
)

func main() {
	_, err := os.ReadFile("nao-existe.txt")
	fmt.Println(err)
	err = os.WriteFile("pasta-que-nao-existe/a.txt", []byte("oi"), 0644)
	fmt.Println(err)
	_, err = os.ReadFile(".")
	fmt.Println(err)
}
$ go run main.go
open nao-existe.txt: no such file or directory
open pasta-que-nao-existe/a.txt: no such file or directory
read .: is a directory

Para reagir a um desses de forma específica, use errors.Is(err, fs.ErrNotExist) (aula errors.Is e errors.As).

package main

import (
	"bufio"
	"fmt"
	"os"
)

func main() {
	os.WriteFile("diario.txt", []byte("acordei\nestudei Go\n"), 0644)

	if err != nil {
		fmt.Println(err)
		return

linhas: 2

Resumo

  • os.WriteFile e os.ReadFile gravam e leem tudo de uma vez.
  • bufio.Scanner lê linha a linha, de arquivos ou de os.Stdin.
  • Confira o err de cada operação e feche com defer f.Close().
