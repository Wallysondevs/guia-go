Instalação e versão (go version)

Antes de escrever código você precisa do Go instalado. Nesta aula você instala, confere a versão com go version e descobre onde o Go guarda as coisas com go env.

Você vai aprender
  • Instalar o Go pelo site oficial (go.dev/dl) no seu sistema.
  • Conferir a instalação com go version e which go.
  • Ler as variáveis do Go com go env: GOOS, GOARCH, GOPATH, GOROOT.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Instalando

O Go oficial vem de go.dev/dl. Escolha o instalador do seu sistema:

SistemaComo instalar
WindowsBaixe o .msi e avance o instalador. Depois feche e abra de novo o terminal.
macOSBaixe o .pkg e instale. Ou, com Homebrew, brew install go.
LinuxBaixe o .tar.gz, extraia em /usr/local e ponha /usr/local/go/bin no PATH. Os pacotes das distros (apt install golang) costumam vir com uma versão mais antiga.

No Linux, o passo a passo oficial é este (troque o nome do arquivo pela versão que você baixou):

sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.27.3.linux-amd64.tar.gz
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.profile

2. Conferindo a versão

O primeiro comando de todo mundo depois de instalar é o go version. Ele mostra a versão, o sistema e a arquitetura:

$ go version
go version go1.27.3 linux/amd64
go1.27.3
a versão do Go: 1.27, correção 3.
linux
o sistema operacional (GOOS).
amd64
a arquitetura do processador (GOARCH): 64 bits Intel/AMD.

Para saber qual arquivo go o terminal está usando, use which go (no Windows, where go). Neste computador o which achou um atalho em /usr/local/bin, e o readlink -f mostrou para onde ele aponta, a pasta /usr/local/go/bin da instalação oficial:

$ which go
/usr/local/bin/go
$ readlink -f "$(which go)"
/usr/local/go/bin/go

3. As variáveis do Go: go env

O go env mostra a configuração da ferramenta. Passando nomes, ele mostra só esses valores, um por linha:

$ go env GOOS GOARCH
linux
amd64
$ go env GOROOT GOPATH GOCACHE
/usr/local/go
/home/ana/go
/home/ana/.cache/go-build
VariávelO que é
GOOS / GOARCHSistema e processador para os quais o Go compila. Mudá-los é o build cruzado.
GOROOTOnde o próprio Go está instalado.
GOPATHA pasta de trabalho do Go na sua casa (por padrão ~/go). Lá ficam os módulos baixados e os programas instalados com go install.
GOCACHEO cache de compilação, que deixa a segunda compilação muito mais rápida.

4. A versão de dentro do programa

O pacote runtime sabe a versão e o sistema em que o programa foi compilado:

package main

import (
	"fmt"
	"runtime"
)

func main() {
	fmt.Println("versão:", runtime.Version())
	fmt.Println("sistema:", runtime.GOOS)
	fmt.Println("arquitetura:", runtime.GOARCH)
}
$ go run main.go
versão: go1.27.3
sistema: linux
arquitetura: amd64

Quando dá errado

O terminal não acha o go

Se o Go não estiver no PATH, o terminal não encontra o programa. Para mostrar isso sem desinstalar nada, rodamos o go version com um PATH sem a pasta do Go, usando env PATH=…:

$ env PATH=/usr/bin:/bin go version
env: ‘go’: No such file or directory

A solução é pôr /usr/local/go/bin no PATH (veja o passo da seção 1) e abrir um terminal novo. No Windows, feche e reabra o terminal depois de instalar. No Prompt de Comando a mensagem é 'go' não é reconhecido como um comando interno ou externo.

Subcomando que não existe

Um erro de digitação no subcomando também é avisado pela ferramenta:

$ go rum main.go
go rum: unknown command
Run 'go help' for usage.

Resumo

  • Instale pelo go.dev/dl e confira com go version.
  • go env mostra a configuração; GOOS e GOARCH dizem para onde o Go compila.
  • Se o terminal não acha o go, falta a pasta do Go no PATH.
