Structs e Métodos

Uma struct junta vários valores numa coisa só: uma pessoa tem nome e idade; uma conta tem dono e saldo. E um método é uma função ligada a um tipo, chamada com ponto: conta.Depositar(25). É assim que Go organiza dados e comportamento, sem classes.

Você vai aprender
  • Declarar type Nome struct { … }, criar valores e acessar campos.
  • Escrever métodos com receptor de valor (c Conta) e de ponteiro (c *Conta).
  • Embutir uma struct em outra para reaproveitar campos e métodos.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

Dá para criar com os nomes dos campos (Pessoa{Nome: "Ana", Idade: 30}, o jeito recomendado) ou na ordem (Pessoa{"Rui", 25}). Campo sem valor fica com o valor zero. E uma struct pode ser anônima, sem type, para usar uma vez só.

2. Métodos: receptor de valor e de ponteiro

O receptor fica entre func e o nome do método. Com (c Conta) o método recebe uma cópia: bom para ler. Com (c *Conta) recebe um ponteiro para o original: necessário para mudar. Veja o DepositarErrado “perder” os 1000:

package main

import "fmt"

type Conta struct {
	Dono  string
	Saldo float64
}

func (c Conta) Resumo() string {
	return fmt.Sprintf("%s: R$ %.2f", c.Dono, c.Saldo)
}

func (c *Conta) Depositar(valor float64) {
	c.Saldo += valor
}

func (c Conta) DepositarErrado(valor float64) {
	c.Saldo += valor // muda só a cópia
}

func main() {
	c := Conta{Dono: "Ana", Saldo: 50}
	c.Depositar(25)
	fmt.Println(c.Resumo())
	c.DepositarErrado(1000)
	fmt.Println(c.Resumo())
}
$ go run main.go
Ana: R$ 75.00
Ana: R$ 75.00

3. Embutindo structs

Pôr um tipo dentro de outro sem nome de campo (embedding) faz os campos e métodos dele ficarem acessíveis direto: c.Cidade e c.Local(). É o jeito Go de reaproveitar, no lugar da herança:

package main

import "fmt"

type Endereco struct {
	Cidade string
	UF     string
}

type Cliente struct {
	Nome string
	Endereco // embutido: os campos "sobem" para Cliente
}

func (e Endereco) Local() string {
	return e.Cidade + "/" + e.UF
}

func main() {
	c := Cliente{Nome: "Bia", Endereco: Endereco{"Recife", "PE"}}
	fmt.Println(c.Nome, c.Cidade, c.Local())
	fmt.Printf("%+v\n", c)
}
$ go run main.go
Bia Recife Recife/PE
{Nome:Bia Endereco:{Cidade:Recife UF:PE}}

package main

package main

import "fmt"

type Retangulo struct {
	Largura, Altura float64
}

func (r Retangulo) Area() float64 {
	return r.Largura * r.Altura
}

func main() {
	r := Retangulo{Largura: 3, Altura: 4}
	fmt.Println("área:", r.Area())

Missão: o método Aniversario devia somar 1 à idade, mas não funciona. Troque o receptor para ponteiro, para a saída ser Ana tem 31 anos.

package main

import "fmt"

type Pessoa struct {
	Nome  string
	Idade int
}

func (p Pessoa) Aniversario() {
	p.Idade++
}

func main() {
	ana := Pessoa{Nome: "Ana", Idade: 30}
	ana.Aniversario()
	fmt.Println(ana.Nome, "tem", ana.Idade, "anos")
}

package main

import "fmt"

type Pessoa struct {
	Nome  string
	Idade int
}

func (p *Pessoa) Aniversario() {
	p.Idade++
}

func main() {
	ana := Pessoa{Nome: "Ana", Idade: 30}
	ana.Aniversario()
	fmt.Println(ana.Nome, "tem", ana.Idade, "anos")
}

Ana tem 31 anos

Resumo

  • type X struct { … } agrupa campos; crie com X{Campo: v}.
  • Métodos têm receptor: de valor (cópia) ou de ponteiro (muda o original).
  • Embutir um tipo reaproveita seus campos e métodos.
