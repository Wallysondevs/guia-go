Embutindo arquivos (embed)

Às vezes o programa precisa de um arquivo junto: um modelo de texto, uma página HTML, um arquivo de configuração. Com a diretiva //go:embed, o arquivo vai para dentro do executável na compilação. Você entrega um arquivo só, e ele continua funcionando mesmo se o original sumir.

Você vai aprender
  • Embutir um arquivo numa string ou num []byte com //go:embed.
  • Embutir vários arquivos num embed.FS e ler como um sistema de arquivos.
  • Provar que o conteúdo foi para dentro do executável.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. Um arquivo numa variável

A linha //go:embed nome fica logo acima de uma variável de pacote. O import _ "embed" é obrigatório quando você não usa nada do pacote pelo nome:

package main

import (
	_ "embed"
	"fmt"
	"strings"
)

//go:embed mensagem.txt
var mensagem string

//go:embed versao.txt
var versao []byte

func main() {
	fmt.Print(mensagem)
	fmt.Println("versão:", strings.TrimSpace(string(versao)))
}

2. Vários arquivos: embed.FS

Com um padrão como modelos/*.txt, a variável é um embed.FS, um pequeno sistema de arquivos só de leitura:

package main

import (
	"embed"
	"fmt"
	"io/fs"
)

//go:embed modelos/*.txt
var modelos embed.FS

func main() {
	arquivos, _ := fs.Glob(modelos, "modelos/*.txt")
	for _, nome := range arquivos {
		dados, _ := modelos.ReadFile(nome)
		fmt.Printf("%s: %s", nome, dados)
	}
}
Oi, {{nome}}!
Até logo, {{nome}}.
$ go run .
modelos/oi.txt: Oi, {{nome}}!
modelos/tchau.txt: Até logo, {{nome}}.

//go:embed dentro de uma função

A diretiva só vale para variáveis de pacote (fora das funções):

package main

import (
	_ "embed"
	"fmt"
)

func main() {
	//go:embed dados.txt
	var dados string
	fmt.Println(dados)
}
$ go run .
# embederro2
./main.go:9:4: go:embed cannot apply to var inside func

Resumo

  • //go:embed põe arquivos dentro do executável.
  • Um arquivo vai para string ou []byte; vários, para embed.FS.
  • A diretiva fica acima de uma variável de pacote, e o arquivo precisa existir na compilação.
