Tabela de testes

Testar uma função com dez entradas diferentes não pede dez funções de teste. O jeito Go é a tabela de testes: uma lista de casos (entrada e resultado esperado) e um laço que confere cada um, com t.Run dando nome a cada caso.

Você vai aprender
  • Montar os casos num []struct{…} e percorrer com for.
  • Criar subtestes com t.Run(nome, …) e rodar um só com -run.
  • Medir quanto do código os testes cobrem com go test -cover.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. A tabela

Usando o mesmo pacote calc da aula go test:

package calc

import "testing"

func TestMediaTabela(t *testing.T) {
	casos := []struct {
		nome string
		nums []int
		want float64
	}{
		{"vazia", nil, 0},
		{"um número", []int{5}, 5},
		{"pares", []int{2, 4}, 3},
		{"com fração", []int{1, 2}, 1.5},
	}
	for _, c := range casos {
		t.Run(c.nome, func(t *testing.T) {
			if got := Media(c.nums...); got != c.want {
				t.Errorf("Media(%v) = %v; queria %v", c.nums, got, c.want)
			}
		})
	}
}

2. Um caso só e a cobertura

O -run aceita Teste/subteste. E o -cover diz qual porcentagem das linhas do pacote os testes fizeram rodar:

$ go test -run 'TestMediaTabela/pares' -v
=== RUN   TestMediaTabela
=== RUN   TestMediaTabela/pares
--- PASS: TestMediaTabela (0.00s)
    --- PASS: TestMediaTabela/pares (0.00s)
PASS
ok  	calc	0.002s
$ go test -cover
PASS
coverage: 100.0% of statements
ok  	calc	0.002s

Deu 100%: a tabela chama Media com lista vazia (passa pelo if) e com números (passa pela conta, que chama Soma). Se você apagar o caso vazia, a linha do return 0 deixa de rodar e a cobertura cai.

Quando dá errado

Um caso quebra, os outros continuam

Tirando do Media o cuidado com a lista vazia, a divisão vira 0/0, que em float64 dá NaN (“não é um número”). Só o caso vazia falha, e a saída diz qual:

Arquivo de apoio desta missão, calc.go (crie junto com o calc_test.go):

package calc

// Soma devolve a soma de todos os números.
func Soma(nums ...int) int {
	total := 0
	for _, n := range nums {
		total += n
	}
	return total
}

// Media devolve a média; com lista vazia, devolve 0.
func Media(nums ...int) float64 {
	if len(nums) == 0 {
		return 0
	}
	return float64(Soma(nums...)) / float64(len(nums))
}

Resumo

  • Casos num slice de struct, conferidos num laço.
  • t.Run dá nome a cada caso; -run 'Teste/caso' roda um só.
  • go test -cover mede a cobertura.
