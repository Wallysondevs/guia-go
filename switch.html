switch

Quando um if vira uma escada de else if, o switch deixa tudo mais limpo. Em Go ele tem duas vantagens sobre C e Java: não precisa de break (cada case para sozinho) e o case aceita vários valores ou condições inteiras.

Você vai aprender
  • switch valor com case, vários valores e default.
  • switch sem expressão, no lugar de if/else if.
  • Inicialização no switch e o raro fallthrough.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. switch com valor e sem valor

package main

import "fmt"

func main() {
	dia := "sábado"
	switch dia {
	case "sábado", "domingo":
		fmt.Println("fim de semana")
	case "sexta":
		fmt.Println("quase lá")
	default:
		fmt.Println("dia útil")
	}

	nota := 8
	switch {
	case nota >= 9:
		fmt.Println("A")
	case nota >= 7:
		fmt.Println("B")
	default:
		fmt.Println("C")
	}
}
$ go run main.go
fim de semana
B

No segundo switch não há valor depois da palavra: cada case é uma condição, conferida em ordem. É o jeito Go de escrever uma escada de if/else if.

2. Inicialização e fallthrough

Como no if, dá para declarar algo antes do valor. E o fallthrough obriga a entrar também no case seguinte, sem conferir (use pouco):

package main

import (
	"fmt"
	"runtime"
)

func main() {
	switch n := 2; n {
	case 1:
		fmt.Println("um")
	case 2:
		fmt.Println("dois")
		fallthrough
	case 3:
		fmt.Println("três (veio pelo fallthrough)")
	case 4:
		fmt.Println("quatro")
	}

	fmt.Println("sistema:", runtime.GOOS)
	switch runtime.GOOS {
	case "windows":
		fmt.Println("use main.exe")
	default:
		fmt.Println("use ./main")
	}
}
$ go run main.go
dois
três (veio pelo fallthrough)
sistema: linux
use ./main

Na sua máquina, a linha sistema: mostra o seu sistema; esta saída veio de um Linux.

Quando dá errado

O mesmo case duas vezes 
package main

import "fmt"

func main() {
	n := 1
	switch n {
	case 1:
		fmt.Println("um")
	case 1:
		fmt.Println("de novo")
	}
}

case de outro tipo 
package main

func main() {

	}

Referência rápida

Você escreveO que faz
switch x { case 1, 2: … default: … }Compara x com cada caso.
switch { case x > 0: … }Cada caso é uma condição.
switch v := f(); v { … }Com inicialização.
fallthroughEntra também no próximo caso.

Missão: use um switch no mes para escrever a estação: 12, 1, 2 → verão; 3, 4, 5 → outono; 6, 7, 8 → inverno; default → primavera. Com o mês 7, a saída deve ser inverno.

package main

import "fmt"

func main() {
	mes := 7
	fmt.Println(mes)
}

package main

import "fmt"

func main() {
	mes := 7
	switch mes {
	case 12, 1, 2:
		fmt.Println("verão")
	case 3, 4, 5:
		fmt.Println("outono")
	case 6, 7, 8:
		fmt.Println("inverno")
	default:
		fmt.Println("primavera")
	}
}

inverno

Resumo

  • switch para sozinho em cada case, sem break.
  • Um case aceita vários valores; default pega o resto.
  • Sem valor depois do switch, cada case é uma condição.
