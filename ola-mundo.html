Olá, Mundo

Todo curso começa com um programa que escreve Olá, mundo!. Em Go ele tem só sete linhas, e cada uma ensina uma regra da linguagem. Nesta aula você escreve, roda e entende cada pedaço.

Você vai aprender
  • As três partes de todo programa Go: package main, import e func main().
  • A diferença entre fmt.Println e fmt.Print.
  • Os erros mais comuns do primeiro programa, com a mensagem real do compilador.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. O programa

Crie uma pasta, abra um editor de texto e salve este conteúdo num arquivo chamado main.go. Depois, no terminal, dentro dessa pasta, rode go run main.go:

package main

import "fmt"

func main() {
	fmt.Println("Olá, mundo!")
}
$ go run main.go
Olá, mundo!

2. Linha por linha

package main
todo arquivo Go pertence a um pacote. O pacote main é especial: é o que vira um programa executável.
import "fmt"
traz o pacote fmt (de format), da biblioteca padrão, que escreve e formata texto.
func main()
a função por onde o programa começa. Quando ela termina, o programa termina.
fmt.Println(…)
escreve os valores e pula uma linha no fim. O P maiúsculo importa (veja o Nível 2: nomes com maiúscula são exportados).

As chaves { } marcam onde a função começa e termina. Em Go a chave de abertura tem que ficar na mesma linha do func main(): isso não é gosto, é regra (veja “Quando dá errado”).

3. Println e Print

O Println aceita vários valores, separa com espaço e pula linha no fim. O Print não pula linha: para isso você escreve \n, a “quebra de linha”.

package main

import "fmt"

func main() {
	fmt.Println("Olá, mundo!")
	fmt.Println("Meu nome é Ana", "e tenho", 30, "anos")
	fmt.Print("sem quebra de linha ")
	fmt.Print("no fim\n")
}
$ go run main.go
Olá, mundo!
Meu nome é Ana e tenho 30 anos
sem quebra de linha no fim

Repare que o número 30 entrou sem aspas: ele é um número, não um texto. O Println sabe escrever os dois.

Quando dá errado

A chave na linha de baixo

Quem vem de C ou Java às vezes põe a { na linha seguinte. Em Go isso não compila:

package main

import "fmt"

func main()
{
	fmt.Println("Olá, mundo!")
}
$ go run main.go
# command-line-arguments
./main.go:6:1: syntax error: unexpected semicolon or newline before {

O Go põe um ponto e vírgula invisível no fim da linha func main(), e aí a função fica “sem corpo”. Mantenha a { na mesma linha.

Texto com aspas simples

Em Go, texto (string) vai entre aspas duplas. Aspas simples são para um caractere só (uma rune, aula Strings e Runes):

package main

import "fmt"

func main() {
	fmt.Println('Olá, mundo!')
}
$ go run main.go
# command-line-arguments
./main.go:6:14: more than one character in rune literal
Esqueceu o package main

Com outro nome de pacote, o arquivo vira uma biblioteca, e o go run não sabe o que executar:

package ola

import "fmt"

func main() {
	fmt.Println("Olá, mundo!")
}
$ go run main.go
package command-line-arguments is not a main package

package main

import "fmt"

func main() {
	fmt.Println("Olá, mundo!")
	// escreva a segunda linha aqui
}

package main

import "fmt"

func main() {
	fmt.Println("Olá, mundo!")
	fmt.Println("Estou aprendendo Go")
}

Olá, mundo!
Estou aprendendo Go

Missão: use fmt.Println com três valores separados por vírgula para escrever Ana tem 30 anos (o 30 sem aspas).

package main

import "fmt"

func main() {
	fmt.Println("Ana tem")
}

package main

import "fmt"

func main() {
	fmt.Println("Ana tem", 30, "anos")
}

Ana tem 30 anos

Resumo

  • Todo programa tem package main, os import e a func main().
  • fmt.Println escreve e pula linha; fmt.Print não pula.
  • A { fica na mesma linha; texto vai entre aspas duplas.
