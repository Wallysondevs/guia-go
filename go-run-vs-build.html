go run e go build

O go run compila e roda na hora, sem deixar nada na pasta. O go build compila e deixa o executável, que você pode rodar quantas vezes quiser e até copiar para outro computador com o mesmo sistema.

Você vai aprender
  • Usar go run no dia a dia e go build para gerar o programa final.
  • Escolher o nome do executável com go build -o.
  • Ver que o executável roda sozinho, sem o Go.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. go run: compila, roda e joga fora

Com o go run, o Go compila numa pasta temporária, roda e apaga. A pasta continua só com o código:

package main

import "fmt"

func main() {
	fmt.Println("Olá, mundo!")
}
$ ls
main.go
$ go run main.go
Olá, mundo!
$ ls
main.go

2. go build: deixa o executável

O go build não mostra nada quando dá certo: ele é silencioso. Mas, depois dele, aparece um arquivo novo, o executável, com o nome do arquivo sem o .go. No Linux e no macOS você roda com ./ na frente; no Windows ele se chama main.exe:

$ go build main.go
$ ls
main
main.go
$ ./main
Olá, mundo!
$ du -h main | cut -f1
2.3M

O executável tem alguns megabytes porque leva junto tudo de que precisa, inclusive o runtime do Go. Por isso ele roda num computador sem o Go instalado.

3. Escolhendo o nome com -o

O -o (de output, saída) dá o nome do arquivo gerado:

$ go build -o saudacao main.go
$ ./saudacao
Olá, mundo!
go build
compila.
-o saudacao
grava o executável com o nome saudacao.
main.go
o arquivo a compilar.

4. Qual usar?

SituaçãoUse
Testar uma mudança rápidago run main.go
Entregar o programa para alguémgo build -o nome
Rodar o mesmo programa muitas vezesgo build uma vez e depois ./nome

Quando dá errado

O arquivo não existe

Rodar go run main.go numa pasta sem esse arquivo (aqui, a pasta vazio):

$ go run main.go
stat main.go: no such file or directory

Confira com ls (ou dir, no Windows) se você está na pasta certa.

Esqueceu o ./

No Linux e no macOS, o terminal não procura programas na pasta atual. Sem o ./, ele não acha o executável recém-criado:

$ saudacao
bash: line 1: saudacao: command not found

Referência rápida

Você escreveO que faz
go run main.goCompila e roda, sem deixar arquivo.
go build main.goGera o executável main (main.exe no Windows).
go build -o nome main.goGera o executável com o nome escolhido.
./nomeRoda o executável da pasta atual (Linux/macOS).

Exercícios

1. Rodar na hora

Complete para compilar e rodar sem deixar arquivo:

go main.go

2. Dar nome

Complete para gerar o executável app:

go build app main.go

Resumo

  • go run compila e roda na hora; go build deixa o executável.
  • O go build é silencioso quando dá certo.
  • -o escolhe o nome; no Linux/macOS, rode com ./.
