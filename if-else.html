if e else

O if é uma bifurcação: o programa confere uma condição e segue por um caminho ou por outro. Em Go ele não usa parênteses em volta da condição, mas as chaves são obrigatórias. E tem um truque próprio: declarar uma variável na mesma linha do if.

Você vai aprender
  • if, else if e else, com chaves obrigatórias.
  • Comparações (==, !=, <, >=…) e lógica (&&, ||, !).
  • O if v, err := …; err == nil, muito usado com erros.
Sobre as saídas. Todas as saídas desta aula foram colhidas rodando o código de verdade, com Go 1.27.3 num Linux (linux/amd64), na pasta ~/projetos da usuária fictícia ana, no computador notebook. As mensagens de erro do Go aparecem em inglês, exatamente como a ferramenta escreveu: nunca traduzimos nem inventamos saída. A explicação em português vem ao lado.

1. if, else if, else

package main

import "fmt"

func main() {
	idade := 17
	if idade >= 18 {
		fmt.Println("pode tirar carteira")
	} else if idade >= 16 {
		fmt.Println("pode votar, mas não dirigir")
	} else {
		fmt.Println("ainda não vota")
	}

	nota, faltas := 7.5, 3
	if nota >= 7 && faltas <= 5 {
		fmt.Println("aprovada")
	}
	if !(nota < 5) || faltas > 10 {
		fmt.Println("não precisa de recuperação")
	}
}
$ go run main.go
pode votar, mas não dirigir
aprovada
não precisa de recuperação

As condições são conferidas de cima para baixo, e só o primeiro bloco verdadeiro roda. Com idade 17, a primeira é falsa e a segunda verdadeira.

OperadorQuer dizer
== / !=igual / diferente
< <= > >=menor, menor ou igual, maior, maior ou igual
&&E: as duas condições verdadeiras
||OU: pelo menos uma verdadeira
!NÃO: inverte

2. if com inicialização

Antes da condição, separado por ;, você pode declarar variáveis que só existem dentro do if e do else. É o jeito idiomático de testar um erro:

package main

import (
	"fmt"
	"strconv"
)

func main() {
	if n, err := strconv.Atoi("42"); err == nil {
		fmt.Println("número válido:", n)
	} else {
		fmt.Println("erro:", err)
	}

	if n, err := strconv.Atoi("4x2"); err == nil {
		fmt.Println("número válido:", n)
	} else {
		fmt.Println("erro:", err)
	}
}
$ go run main.go
número válido: 42
erro: strconv.Atoi: parsing "4x2": invalid syntax
n, err := strconv.Atoi("42")
a inicialização: roda primeiro.
;
separa a inicialização da condição.
err == nil
a condição: “não houve erro”.

Quando dá errado

A condição precisa ser bool

Em Go, número não vira verdadeiro ou falso sozinho, como em C ou Python:

package main

import "fmt"

func main() {
	quantidade := 3
	if quantidade {
		fmt.Println("tem itens")
	}
}
$ go run main.go
# command-line-arguments
./main.go:7:5: non-boolean condition in if statement

Escreva a comparação inteira: if quantidade > 0.

Sem chaves 
package main

import "fmt"

func main() {
	idade := 20
	if idade >= 18
		fmt.Println("maior de idade")
}
$ go run main.go
# command-line-arguments
./main.go:8:32: syntax error: unexpected newline, expected { after if clause
Variável do if usada fora dele

O que é declarado na inicialização morre no fim do if/else:

package main

import "fmt"

func main() {
	if total := 10; total > 5 {
		fmt.Println("grande")
	}
	fmt.Println(total)
}
$ go run main.go
# command-line-arguments
./main.go:9:14: undefined: total

Missão: use o if com inicialização para converter "abc" com strconv.Atoi. Se der erro, escreva texto inválido.

package main

import (
	"fmt"
	"strconv"
)

func main() {
	entrada := "abc"
	n, _ := strconv.Atoi(entrada)
	fmt.Println(n)
}

package main

import (
	"fmt"
	"strconv"
)

func main() {
	entrada := "abc"
	if n, err := strconv.Atoi(entrada); err != nil {
		fmt.Println("texto inválido")
	} else {
		fmt.Println(n)
	}
}

Resumo

  • if sem parênteses, com chaves obrigatórias; a condição é sempre bool.
  • &&, || e ! combinam condições.
  • if v, err := f(); err != nil declara e testa numa linha.
